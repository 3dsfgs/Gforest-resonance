## 概述

两种可区分敌人（数值 + 外观 + **行为**）：

| 类型 | 类 / 场景 | 血量 | 移速 | 行为 | 外观 |
|------|-----------|------|------|------|------|
| **侦察（快而脆）** | `Enemy` / `enemy.tscn` | 2 | 420 | **中距远程射击** + 保持射程 | `robot_1` |
| **坦克（慢而肉）** | `EnemyBrute` / `enemy_brute.tscn` | 5 | 200 | **蓄力冲撞**（冷却后猛冲） | `robot_2`（更大） |

刷怪约定：

- `EnemySpawn*` → 侦察  
- `EnemyBruteSpawn*` → 坦克  

| 关卡 | 配置 |
|------|------|
| level1 | 1× 侦察 |
| level2 | 1× 侦察 + 1× 坦克 |
| level3 | 2× 侦察 + 1× 坦克 |

---

## 血量 Bug 修复

`HeartHealth::set_max` 原先在提高上限时用 `min(旧心数, 新上限)`，导致：

`Enemy` 设为 2 心 → `EnemyBrute` 再 `set_max(5)` 时心数仍停在 **2**。

现已改为：**提高 max 时补满当前心数**。坦克需约 5 发脉冲才能击杀。

---

## 行为摘要

**侦察远程**

- 距离过近 → 后退；过远 → 靠近；中距 → 站住射击  
- 子弹 `configure_as_enemy_shot()`：只打玩家/墙，不打友军  

**坦克冲撞**

- 进入触发距离 → 短蓄力停步 → 朝玩家方向高速冲刺 → 冷却后恢复走速
