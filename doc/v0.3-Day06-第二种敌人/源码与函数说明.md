# v0.3 Day06 源码与函数说明

## 1. 血量：`HeartHealth::set_max`

```cpp
if (new_max > max_hearts)
    hearts = new_max;          // 提高上限 → 补满（EnemyBrute 构造）
else
    hearts = std::min(hearts, new_max);  // 降低 → 钳制
```

## 2. 常量（行为）

| 常量 | 用途 |
|------|------|
| `enemy_charge_trigger_range` | 坦克开始蓄力的距离 |
| `enemy_charge_speed_mult` | 冲刺相对走速倍率 |
| `enemy_charge_duration` / `cooldown` / `windup` | 冲刺时序 |
| `enemy_ranged_range` / `min_range` | 侦察射击距离带 |
| `enemy_ranged_fire_rate` | 侦察射速 |

## 3. `EnemyController::Behavior`

| 值 | 谁设置 | 移动 | 攻击 |
|----|--------|------|------|
| `ScoutRanged` | 刷 `EnemySpawn*` | 风筝站位 | `character_shoot` → Level 生成敌弹 |
| `BruteCharge` | 刷 `EnemyBruteSpawn*` | 追击 + 冲撞 | 接触伤害（原有） |

`Level::spawn_enemies_from_markers` 里 `controller->set_behavior(...)`。

## 4. 敌弹

`Projectile::configure_as_enemy_shot()`：

- `m_hostile_to_player = true`
- mask = Walls | Player  
- 命中 `Player` 扣心；忽略 `Enemy`

`Level::on_enemy_spawn_projectile` → `spawn_projectile_from_marker(..., true)`。

## 5. 调参

| 目标 | 改哪里 |
|------|--------|
| 坦克血量 | `enemy_brute_hearts` |
| 冲撞频率/距离 | `enemy_charge_*` |
| 侦察射速/射程 | `enemy_ranged_*` |
