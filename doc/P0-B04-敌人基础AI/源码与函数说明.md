## 2. `src/entity/controller/enemy_controller.hpp`

**文件含义**：敌人 AI 控制器声明，继承 `CharacterController`。负责每帧计算朝向玩家的移动与旋转输入，通过信号驱动 `Character::on_character_movement` / `on_character_rotate`，与 `PlayerController` 对称。

### 类：`class EnemyController`

#### 公开接口

| 函数 | 说明 |
|------|------|
| `EnemyController()` | 构造：将 `m_input_mode` 设为 `InputMode::AI` |
| `~EnemyController()` | 默认析构 |
| `process_action_input(input, delta_time)` | 覆盖基类；敌人无射击/技能，**空实现** |
| `process_movement_input(input, delta_time)` | 覆盖基类；计算朝向玩家的单位方向，发射 `character_move` 信号 |
| `process_rotation_input(input, delta_time)` | 覆盖基类；计算面向玩家的角度，发射 `character_rotate` 信号 |

#### 私有接口

| 函数 | 说明 |
|------|------|
| `Player* find_player() const` | 从场景树查找关卡内唯一 `Player` 节点；找不到返回 `nullptr` |

#### 前向声明

| 类型 | 说明 |
|------|------|
| `godot::Input` | 虚函数参数类型，避免在头文件中 include 完整 Input 头 |
| `Player` | `find_player` 返回类型 |

#### 继承成员（来自 `CharacterController`，B04 使用）

| 成员 | B04 用途 |
|------|----------|
| `m_input_mode` | 构造时设为 `AI`，标识非玩家输入 |
| `m_rotation_angle` | 每帧写入目标朝向角，经 `character_rotate` 传给 `Character` |
| `m_elapsed_time` | 基类 `_process` 用于周期性 `position_changed` 信号（调试输出） |

## 3. `src/entity/controller/enemy_controller.cpp`

**文件含义**：`EnemyController` 全部方法实现。核心为「查找玩家 → 直线追击 → 面向玩家」的降级 AI（无巡逻、无视野锥）。

### 函数说明

| 函数 | 说明 |
|------|------|
| `EnemyController::EnemyController()` | `m_input_mode = InputMode::AI` |
| `find_player()` | ① `get_parent()` 得 `Enemy` 节点；② `get_parent()` 得 `Level`；③ `find_child(name::character::player, true, false)` 递归查找名为 `"Player"` 的节点并 `gdcast<Player>` |
| `process_action_input(...)` | 空函数；预留 B04+ 敌人远程攻击等扩展 |
| `process_movement_input(...)` | 见下方分支表 |
| `process_rotation_input(...)` | 见下方分支表 |

**`process_movement_input` 分支逻辑**

| 条件 | 行为 |
|------|------|
| `find_player()` 为 `nullptr` | 发射零向量 `character_move`，敌人停止 |
| 玩家存在但 `!is_alive()` | 同上，玩家死亡后不再追击 |
| 距玩家 < `8.0` px（`stop_distance`） | 发射零向量，避免重叠时抖动 |
| 否则 | `to_player.normalized()` → 发射 `character_move` |

**`process_rotation_input` 分支逻辑**

| 条件 | 行为 |
|------|------|
| 玩家无效或已死亡 | 直接返回，不更新朝向 |
| `rotation_dir.is_zero_approx()` | 与玩家重合，跳过 |
| 否则 | `m_rotation_angle = rotation_dir.angle() + deg_to_rad(90.0)`，与玩家鼠标瞄准偏移一致；发射 `character_rotate` |

> **设计说明**：`+90°` 与 `PlayerController::process_rotation_input` 保持一致，因精灵贴图默认朝向需补偿。

## 7. `src/entity/character/player.cpp`（本次增量）

**文件含义**：玩家实体实现。B04 在 `process_slide_collisions` 中优先检测 `Enemy` 碰撞体并扣心。

### 函数说明

| 函数 | 变更说明 |
|------|----------|
| `Player::Player()` | 无变更 |
| `Player::_ready()` | 无变更 |
| `Player::process_slide_collisions()` | **B04 增量**：见下方逻辑表 |
| `Player::handle_zone_contact(body)` | 无变更 |
| `Player::_bind_methods()` | 无变更 |

**`process_slide_collisions` 循环逻辑（B04 后）**

| 顺序 | 检测 | 行为 |
|------|------|------|
| 1 | 遍历 `get_slide_collision(i)` | 收集 `collider` 的 `instance_id` 到 `touching` |
| 2 | `cast_to<Enemy>(collider)` 成功 | `take_damage(enemy_contact_damage_hearts)`；成功则 Console `enemy contact`；`continue`（不走伤害区逻辑） |
| 3 | `id` 不在 `m_active_zone_colliders` | 调用 `handle_zone_contact`（伤害区/即死区） |
| 4 | 循环结束 | `m_active_zone_colliders = move(touching)` |

> **与 B02 协作**：`take_damage(1)` 内部检查无敌帧；重叠期间重复调用返回 `false`，不会连扣。无敌结束后若仍重叠，下一帧 `move_and_slide` 仍会触发扣心。

> **include 增量**：`#include "entity/character/enemy.hpp"` 用于 `cast_to<Enemy>`。

## 10. `src/entity/controller/character_controller.hpp` / `.cpp`（只读，B04 依赖链）

**文件含义**：角色输入控制器基类。`EnemyController` 与其共享 `_process` 调度与信号定义。

### 基类 `_process` 对 B04 的意义

```
每帧（非编辑器）:
  process_movement_input  → EnemyController 追击
  process_rotation_input  → EnemyController 面向玩家
  process_action_input    → EnemyController 空实现
  每秒 emit position_changed（调试）
```

### 信号（由基类 `_bind_methods` 注册）

| 信号名 | 参数 | B04 发射方 |
|--------|------|------------|
| `character_move` | `Vector2`, `double` | `EnemyController::process_movement_input` |
| `character_rotate` | `double`, `double` | `EnemyController::process_rotation_input` |
| `character_shoot` | — | 敌人未使用 |

## 12. 运行时调用链

### 刷怪 → AI 挂载

```
Level::_ready
  → spawn_enemies_from_markers
    → instantiate Enemy
    → set_controller(EnemyController)   // add_child 前
    → add_child(enemy)
  → Enemy::_ready
    → add_child(EnemyController)
    → connect character_move / rotate / shoot
```

### 每帧追击

```
EnemyController::_process (继承)
  → process_movement_input
    → find_player
    → emit character_move(direction, dt)
  → Character::on_character_movement
    → move_and_slide
    → process_slide_collisions (Player 侧处理接触)
  → process_rotation_input
    → emit character_rotate(angle, dt)
  → Character::on_character_rotate
```

### 敌人接触扣心

```
Enemy move_and_slide 与 Player 碰撞层重叠
  → Player::on_character_movement
    → move_and_slide
    → Player::process_slide_collisions
      → cast_to<Enemy>(collider)
      → take_damage(enemy_contact_damage_hearts)  // B02 无敌帧
      → Console: enemy contact
```

### 脉冲击杀敌人（B03 复用，B04 验收项）

```
Projectile::on_body_entered
  → Enemy::take_damage(projectile_damage_hearts)
  → hearts == 0 → emit died
  → Enemy::on_died → queue_free
```

```cpp
/**
 * 敌人 AI 控制器。
 * 每帧查找 Player，发射 character_move / character_rotate 驱动 Character。
 * 降级策略：无巡逻、无视野锥，始终直线追击。
 */
class EnemyController : public CharacterController;

/** 构造：m_input_mode = InputMode::AI。 */
EnemyController();

/** 敌人无主动技能；预留远程攻击等扩展。 */
void process_action_input(godot::Input* const input, double delta_time) override;

/**
 * 计算朝向玩家的单位方向并发射 character_move。
 * 玩家无效、已死亡或距离 < 8px 时发射零向量。
 */
void process_movement_input(godot::Input* const input, double delta_time) override;

/**
 * 计算面向玩家的角度（+90° 精灵补偿）并发射 character_rotate。
 */
void process_rotation_input(godot::Input* const input, double delta_time) override;

/**
 * 自 Enemy → Level → find_child("Player") 查找玩家。
 * @return 关卡内 Player 指针，未找到则 nullptr。
 */
[[nodiscard]] Player* find_player() const;
```
