## 2. `src/entity/projectile/projectile.hpp`

**文件含义**：脉冲子弹实体类声明，继承 `godot::RigidBody2D`。本次新增碰撞回调 `on_body_entered` 与反弹/命中状态成员。

### 类：`class Projectile`

#### 公开接口

| 函数 | 说明 |
|------|------|
| `void _ready() override` | 设置反弹物理材质、记录起点、施加初速度、连接 `body_entered` |
| `void _process(double delta_time) override` | TTL 与最大飞行距离检查，超时/超距 `queue_free` |
| `get_*` / `set_*` 属性方法 | 子弹速度、TTL、射程等 Godot 属性绑定（既有，未改语义） |

#### 受保护接口（本次新增）

| 函数 | 说明 |
|------|------|
| `void on_body_entered(godot::Node* body)` | `body_entered` 信号槽：处理敌人伤害、反弹误伤、首次反弹标记 |

#### 成员变量

| 成员 | 说明 |
|------|------|
| `m_start_pos` | 发射时全局坐标，用于计算已飞行距离 |
| `m_bounce_point` | 首次碰墙/PhysicsBox 时的全局坐标，误伤距离基准点 |
| `m_hit` | 是否已处理命中（防重复 `queue_free`） |
| `m_has_bounced` | 是否发生过至少一次反弹 |
| `m_velocity` | 初速度冲量大小（默认 `1500`） |
| `m_movement_speed` | 属性：目标移动速度（默认 `1000`，当前冲量逻辑未直接使用） |
| `m_acceleration` | 属性：加速度（预留） |
| `m_time_to_live` | 存活时间（秒），默认 `2.5` |
| `m_max_travel_dist` | 最大飞行距离平方值存储（对外 getter 开方） |

#### Godot 绑定（`_bind_methods` 内新增）

| 绑定 | 说明 |
|------|------|
| `bind_member_function(Projectile, on_body_entered)` | 供 `signal_callback` 连接 `body_entered` |

#### 前向声明（本次新增）

| 类型 | 说明 |
|------|------|
| `godot::Node` | `on_body_entered` 参数类型，避免多余 include |

## 3. `src/entity/projectile/projectile.cpp`

**文件含义**：`Projectile` 全部方法实现。本次核心为 `_ready` 物理材质、 `on_body_entered` 三分支碰撞逻辑。

### 函数说明（按逻辑分组）

#### 初始化

| 函数 | 说明 |
|------|------|
| `Projectile::_ready()` | ① 创建 `PhysicsMaterial`（`bounce=0.85`, `friction=0.2`）并设为 override；② 记录 `m_start_pos`；③ `apply_impulse` 沿朝向施加初速度；④ 连接 `body_entered` → `on_body_entered` |

#### 碰撞处理

| 函数 | 说明 |
|------|------|
| `on_body_entered(body)` | 见下方分支表；`m_hit` 或 `body==nullptr` 时早退 |

**`on_body_entered` 分支逻辑**

| 顺序 | 检测类型 | 条件 | 行为 |
|------|----------|------|------|
| 1 | `Enemy` | `cast_to<Enemy>` 成功 | `take_damage(projectile_damage_hearts)`；Console `pulse hit`；`m_hit=true`；`queue_free` |
| 2 | `Character` | 非 Enemy 的 `Character`（实为 Player） | 若 `!m_has_bounced` → 忽略；若距 `m_bounce_point` > 半径 → 忽略；否则 `take_damage(ricochet_self_damage_hearts)`；Console `ricochet self-hit`；销毁子弹 |
| 3 | `PhysicsBody2D` | 层含 `Walls` 或 `PhysicsObjects` | 首次反弹：`m_has_bounced=true`，记录 `m_bounce_point`，`collision_mask \|= Player`；**不销毁**，由物理引擎反弹 |

> **注意**：敌人分支必须在 `Character` 分支之前，因 `Enemy` 继承 `Character`。

#### 生命周期

| 函数 | 说明 |
|------|------|
| `_process(delta_time)` | 编辑器中跳过；递减 TTL；用 `m_start_pos` 与当前位置距离平方对比 `m_max_travel_dist`；任一超限则 `queue_free` |

#### 属性访问器（既有）

| 函数 | 说明 |
|------|------|
| `get_movement_speed` / `set_movement_speed` | 读写 `m_movement_speed` |
| `get_time_to_live` / `set_time_to_live` | 读写 `m_time_to_live` |
| `get_acceleration` / `set_acceleration` | 读写 `m_acceleration` |
| `get_max_travel_dist` / `set_max_travel_dist` | getter 返回开方后距离；setter 存平方值 |
| `get_velocity` / `set_velocity` | 读写冲量速度 `m_velocity` |

## 9. 运行时调用链

### 玩家射击 → 子弹生成

```
PlayerController → character_shoot
  → Character::on_character_shoot
    → emit spawn_projectile(FiringPoint)
  → Level::on_player_spawn_projectile
    → ProjectileSpawner::spawn_projectile
    → 设置 position/rotation
    → Level::add_child(projectile)
  → Projectile::_ready
    → PhysicsMaterial bounce
    → apply_impulse
    → connect body_entered
```

### 命中敌人

```
Projectile::on_body_entered
  → Enemy::take_damage(1)
    → hearts_changed（敌人无 HUD）
  → queue_free(projectile)
```

### 碰墙反弹 + 贴墙误伤

```
Projectile::on_body_entered (Wall / PhysicsBox)
  → m_has_bounced = true
  → m_bounce_point = 当前坐标
  → collision_mask |= Player
  → 物理引擎反弹（不 queue_free）

（弹回后）
Projectile::on_body_entered (Player as Character)
  → 距 bounce_point ≤ 120px
  → Player::take_damage(1)  // 受 B02 无敌保护
  → queue_free(projectile)
```

## 11. 头文件注释对照表

以下为各头文件中 **P0-B03 相关** 关键声明的文档化注释（建议阅读源码时对照；与本文档一一对应）。

### `constants.hpp`

```cpp
/** 脉冲命中敌人时扣除的心数（P0-B03）。 */

/** 敌人默认心数，供关卡测试（P0-B03）。 */
constexpr inline int enemy_default_hearts{ 3 };

/** 反弹误伤扣心数。 */
```

### `projectile.hpp`

```cpp
/**
 * body_entered 信号槽。
 * - Enemy：扣血并销毁子弹。
 * - Character（玩家）：仅反弹后且距 m_bounce_point 足够近时误伤。
 * - Walls / PhysicsObjects：标记首次反弹并开启 Player 碰撞层，不销毁。
 */
[[signal_slot]] void on_body_entered(godot::Node* body);

/** 发射点全局坐标，用于射程判定。 */
godot::Vector2 m_start_pos{ 0.0, 0.0 };

/** 首次反弹时的全局坐标，误伤距离基准。 */
godot::Vector2 m_bounce_point{ 0.0, 0.0 };

/** 是否已处理命中（防重复销毁）。 */
bool m_hit{ false };

/** 是否已发生过反弹（首发子弹不伤玩家）。 */
bool m_has_bounced{ false };
```

### `enemy.hpp`

```cpp
/** 初始化血量显示并连接 died → on_died。 */
void _ready() override;

/** 心数为 0 时移除敌人节点。 */
[[signal_slot]] void on_died();
```

### `level.hpp`

```cpp
/**
 * 玩家射击回调：从 ProjectileSpawner 取实例，对齐 FiringPoint，加入场景。
```

## 12. 调参与扩展建议

| 需求 | 修改位置 |
|------|----------|
| 脉冲伤害更高 | `combat::projectile_damage_hearts` |
