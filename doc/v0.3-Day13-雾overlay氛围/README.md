## 概述

三间房进入时自动套上森林氛围（不必改每个 `.tscn`）：

| 层 | 效果 |
|----|------|
| **背景** | 向暖绿插值（保留房 2/3 原有 tint 差异） |
| **定向光** | 偏林间暖绿，略降 energy |
| **FogOverlay** | `forest_fog.gdshader`：半透明绿雾 + 缓慢漂移 + 边缘略浓 |

静止截图应能看出「有雾的森林房间」，同时战斗仍可读。

---

## 调参（`atmosphere::`）

| 常量 | 默认 | 含义 |
|------|------|------|
| `fog_density` | 0.28 | 雾浓度（太大糊角色） |
| `fog_drift_speed` | 0.05 | 漂移速度 |
| `background_forest_blend` | 0.4 | 背景绿化程度 |
| `light_energy` | 0.72 | 环境光强度 |

Shader 本体：`project/shaders/forest_fog.gdshader`。
