# v0.3 Day13 源码与函数说明

## 1. 入口

`Level::_ready` 末尾调用 `apply_forest_atmosphere()`（三房共用）。

## 2. `Level::apply_forest_atmosphere`

1. `BackgroundTexture`：`modulate.lerp(森林绿, blend)`  
2. `DirectionalLight2D`：暖绿色 + `atmosphere::light_energy`  
3. 若尚无 `FogOverlay` 节点：  
   - 加载 `res://shaders/forest_fog.gdshader`  
   - 白底 `ImageTexture` 铺满可玩区域  
   - `ShaderMaterial` 设 density / drift / fog_color  
   - `z_index = 18`（盖在角色上形成透雾感）

## 3. 文件

| 路径 | 说明 |
|------|------|
| `project/shaders/forest_fog.gdshader` | 噪声雾 + TIME 漂移 |
| `src/entity/level.cpp` | `apply_forest_atmosphere` |
| `src/core/constants.hpp` | `atmosphere::*`、`path::shader::forest_fog` |
