# v0.3 Day02 源码与函数说明

本文档逐文件说明 Day02「击杀粒子 + 命中/受击音效」涉及的类、函数与调用链。

---

## 1. `src/core/constants.hpp`

### 爆炸 VFX（`combat`）

```cpp
constexpr inline int kill_explosion_frame_count{ 9 };
constexpr inline double kill_explosion_fps{ 18.0 };
constexpr inline float kill_explosion_scale{ 1.35f };
constexpr inline int kill_explosion_z_index{ 12 };
```

### 音效音量（`combat`）

```cpp
constexpr inline float sfx_enemy_hit_volume_db{ 0.0f };
constexpr inline float sfx_enemy_kill_volume_db{ 0.0f };
constexpr inline float sfx_player_hurt_volume_db{ 0.0f };
```

`0.0` = Godot 基准响度。偏响可略降（如 `-4`），偏轻可略升（如 `+3`），**勿**再用调试期的 `50`。

### 资源路径

```cpp
namespace path::audio {
    constexpr inline auto enemy_hit{ "res://assets/audio/sfx/retro/hit2.ogg" };
    constexpr inline auto enemy_kill{ "res://assets/audio/sfx/retro/explosion2.ogg" };
    constexpr inline auto player_hurt{ "res://assets/audio/sfx/retro/hurt2.ogg" };
}

namespace path::vfx {
    constexpr inline auto kill_explosion_dir{
        "res://assets/art/explosions/simple/simpleexplosion" };
}
```

帧文件由 `kill_explosion_dir` + `"%02d.png"` 拼接（`00`…`08`）。

## 2. `src/util/combat_feedback.hpp` / `combat_feedback.cpp`

### 公开 API

| 函数 | 说明 |
|------|------|
| `play_enemy_hit(scene_parent, world_pos)` | 命中音效 |
| `play_enemy_kill(scene_parent, world_pos)` | 击杀音效 |
| `play_player_hurt(scene_parent, world_pos)` | 玩家受击音效 |
| `spawn_kill_explosion(scene_parent, world_pos)` | 击杀爆炸序列帧 |

`world_pos` 目前仅用于 VFX 定位；SFX 使用非空间 `AudioStreamPlayer`，故位置参数被忽略（保留以便日后改回 `AudioStreamPlayer2D`）。

### 内部：`load_audio` / `load_texture`

1. `ResourceLoader::exists(path)` 为假 → 返回空 `Ref`（静默跳过，避免崩溃）
2. 否则 `load(path)`

若再次出现「完全无声」，优先检查：

1. 对应路径是否仍在 `project/assets/audio/` 下  
2. 该目录（或父目录）是否又出现了 `.gdignore`  
3. Godot FileSystem 是否可见并已生成 `.import`

### 内部：`play_one_shot`

```text
memnew(AudioStreamPlayer)
→ scene_parent->add_child
→ set_stream / set_volume_db / set_bus("Master")
→ play()
→ finished → queue_free
```

选用 **非 2D** 播放器：关卡在 `SubViewport` 内时，2D 衰减 + listener 容易踩坑；反馈音效按 UI 级「必听」处理即可。

### 内部：`build_kill_sprite_frames` / `spawn_kill_explosion`

- 每次新建 `SpriteFrames`（**无 static 缓存**，避免退出时静态 `Ref` 析构崩溃）
- 动画名 `"kill"`，不循环，帧率 `kill_explosion_fps`
- `AnimatedSprite2D`：全局坐标、缩放、z_index → `play` → `animation_finished` → `queue_free`

## 3. 接入点

### `projectile.cpp` — 命中扣血

在对敌人成功造成伤害后调用：

```cpp
combat_feedback::play_enemy_hit(this->get_parent(), /* hit position */);
```

与 Day 1 青白闪同一条命中链，只多一层音效。

### `enemy.cpp` — 死亡

在敌人确认死亡、准备移除前：

```cpp
combat_feedback::spawn_kill_explosion(parent, death_pos);
combat_feedback::play_enemy_kill(parent, death_pos);
```

顺序：先挂 VFX，再播击杀音，避免节点已销毁导致 parent 无效。

### `character.cpp` — 玩家受击

在 `take_damage` 成功扣血且为玩家反馈路径时：

```cpp
combat_feedback::play_player_hurt(this->get_parent(), this->get_global_position());
```

与 Day 1 红橙闪 / 屏震 / 无敌帧并行，互不替代。

## 4. 资源与 `.gdignore`

| 目录 | 约定 |
|------|------|
| `project/assets/art/` | 美术；本 Day 用 `art/explosions/simple/` |
| `project/assets/audio/` | 音频；本 Day 用 `audio/sfx/retro/` |

**关键文件**：不得在「正在使用的」`assets/audio` 根目录放置 `.gdignore`。模板里大量未用 Kenney 子目录仍可保留 `.gdignore`。

## 5. 调用链总览

```text
Projectile 命中 Enemy
  → Enemy::take_damage / 扣血
  → combat_feedback::play_enemy_hit
  → AudioStreamPlayer(hit2)

Enemy HP ≤ 0
  → combat_feedback::spawn_kill_explosion
  → AnimatedSprite2D(simpleexplosion**)
  → combat_feedback::play_enemy_kill
  → AudioStreamPlayer(explosion2)

Player::take_damage
  → Day1 闪色 + 屏震 + 无敌
  → combat_feedback::play_player_hurt
  → AudioStreamPlayer(hurt2)
```

## 6. 调参指南

| 目标 | 改哪里 |
|------|--------|
| 爆炸更快/更慢 | `kill_explosion_fps` |
| 爆炸更大/更小 | `kill_explosion_scale` |
| 爆炸被遮挡 | 提高 `kill_explosion_z_index` |
| 整体偏轻/偏响 | 三个 `sfx_*_volume_db` |
| 换音效文件 | `path::audio::*` 指向新 `res://assets/audio/...` |
| 换爆炸序列 | `path::vfx::kill_explosion_dir` + `kill_explosion_frame_count` |

改常量后需 **重新编译 GDExtension**；仅换资源文件且路径不变时，重载 Godot 项目即可。

## 7. 已知限制 / 后续可改进

| 项 | 说明 |
|----|------|
| 无对象池 | 每次命中新建 `AudioStreamPlayer`；短局可接受，高频可再池化 |
| 无失败日志 | `exists` 失败时静默；调试时可临时 `console::print` |
| 非空间音效 | 暂无距离衰减；若要听感分层，再评估 `AudioStreamPlayer2D` + Viewport listener |
| 单套爆炸序列 | 当前仅 `simple/`；**拉伸 ⭐5**：接入 `sonic/ground/regular/…` 多套随机或按敌种 |
| 未做 GPU 粒子 | 按冲刺降级用序列帧；**拉伸 ⭐6**：可选 `GPUParticles2D`（建议 `.tscn` 调好再实例化） |

冲刺计划索引见 [README § 后续优化](./README.md#后续优化未做已记入冲刺拉伸清单)。
