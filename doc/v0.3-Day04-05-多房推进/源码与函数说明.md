# v0.3 Day04–05 源码与函数说明

## 1. 常量（`constants.hpp`）

```cpp
level::room_count = 3
path::scene::Level1 / Level2 / Level3
path::scene::room_paths[3]
collision::player_mask = Walls | NPCs   // 10
collision::trap_mask = Player           // Area2D 检测玩家
event::room_cleared / run_restart
```

## 2. `Main` — 房间调度

| 方法 | 说明 |
|------|------|
| `load_room(index, carry_hearts)` | 移除旧 Level，实例化 `room_paths[index]`，绑信号，可选继承血量 |
| `on_room_cleared(index)` | `load_room(index+1, hearts)` |
| `on_run_restart()` | Victory 后 R → `load_room(0)` |
| `bind_active_level_signals()` | 连 `room_cleared` / `run_restart`；通知 MainDialog / HeartHud |

## 3. `Level` — 清怪语义

| 条件 | 行为 |
|------|------|
| `m_enemy_count==0` 且 `room_index < room_count-1` | `emit room_cleared`（不 Victory） |
| 最后一房清怪 | `transition_to_state(Victory)` |
| Defeat + R | `reset_level()`（本房） |
| Victory + R | `emit run_restart` |

`set_room_index` / `get_player_hearts` / `apply_player_hearts` 供 Main 使用。

## 4. `Player` — 可穿过陷阱

```text
process_slide_collisions
  → 敌人接触伤害（不变）
  → process_area_traps
       遍历 Level 子节点 Area2D
       layer 含 DamageZones / DeathZones
       overlaps_body(this) → handle_zone_area
```

玩家 solid mask 不再含 16/32，故可走进陷阱。

## 5. 场景节点约定

| 节点 | 类型 | layer / mask |
|------|------|--------------|
| `Boundaries/*` | StaticBody2D | layer 8, mask 0 |
| `Wall*` | StaticBody2D | layer 8 |
| `DamageZone*` | **Area2D** | layer 16, mask 1 |
| `DeathPit*` | **Area2D** | layer 32, mask 1 |
| `SpawnPoint` | Marker2D | 必填 |
| `EnemySpawn*` | Marker2D | 前缀 `EnemySpawn` |

陷阱子节点（贴图 / CollisionPolygon）**position 保持 (0,0)**，只移动父节点。

## 6. 调参 / 改布局

- 改刷怪数量：增删 `EnemySpawnN` Marker  
- 改陷阱位置：在编辑器选中 `DamageZone` / `DeathPit` 父节点拖动  
- 加障碍：复制 `Wall`，改名 `Wall4`…，layer 保持 8  
- 改房间顺序：改 `path::scene::room_paths` 与 `room_count`
