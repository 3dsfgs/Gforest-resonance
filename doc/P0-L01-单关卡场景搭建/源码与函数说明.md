## 1. `src/core/constants.hpp`（本次增量）

**文件含义**：全局字符串、碰撞层枚举、战斗数值与场景路径常量。本次在 `name::level`、`level` 命名空间增加关卡节点名与尺寸，并在 `path::scene` 增加敌人场景路径。

### 命名空间 `name::level`（增量）

| 常量 | 值 | 说明 |
|------|-----|------|
| `spawn_point` | `"SpawnPoint"` | 玩家出生 `Marker2D` 节点名 |
| `enemy_spawn_prefix` | `"EnemySpawn"` | 敌人刷点名称前缀；`begins_with` 匹配用 |
| `enemy_spawn1` | `"EnemySpawn1"` | 首个刷点节点名（场景约定，代码用前缀扫描） |
| `boundaries` | `"Boundaries"` | 四面围墙父节点名 |
| `ground` | `"Ground"` | 地面 `ColorRect` 节点名 |
| `debug_zones` | `"DebugZones"` | 调试区（伤害/即死/物理箱）父节点名 |

### 命名空间 `level`（新建）

| 常量 | 值 | 说明 |
|------|-----|------|
| `playable_width` | `2000.0f` | 活动区宽度（像素），与 `level1.tscn` 中 `Ground` 一致 |
| `playable_height` | `1500.0f` | 活动区高度（像素） |
| `wall_thickness` | `40.0f` | 围墙碰撞体厚度；围墙中心距内缘为半厚度 |

### 命名空间 `path::scene`（增量）

| 常量 | 值 | 说明 |
|------|-----|------|
| `Enemy` | `res://scenes/characters/enemy.tscn` | `spawn_enemies_from_markers` 预加载路径 |

### 既有常量（L01 仍依赖，未改语义）

| 常量 | 说明 |
|------|------|
| `name::level::level1` | Level 根节点唯一名 `"Level1"` |
| `name::level::physics_box` | 紫色可推动物理箱，现位于 `DebugZones` 下 |
| `path::scene::Level1` | `Main` 构造时加载的关卡场景 |
| `path::scene::Player` | `_ready` 实例化玩家 |
| `LayerID::Walls` | 值 `8`，围墙 `collision_layer` |

## 2. `src/entity/level.hpp`

**文件含义**：关卡根节点类声明，继承 `godot::Node2D`。负责玩家/子弹/敌人的场景内编排，监听玩家射击与位置调试信号。本次新增两个私有刷点方法。

### 类：`class Level`

#### 公开接口

| 函数 | 说明 |
|------|------|
| `Level()` | 构造：设置唯一名 `Level1`，默认 `activate(true)` |
| `~Level()` | 默认析构 |
| `void _ready() override` | 关卡初始化：查找物理箱、实例化玩家、刷点定位、生成敌人、连接信号 |
| `void _draw() override` | 激活时在鼠标位置绘制瞄准圆点（调试/手感） |
| `void _process(double delta_time) override` | 激活时隐藏系统光标；每帧 `queue_redraw` |
| `void activate(bool active = true)` | 设置关卡是否处于「游玩激活」状态 |
| `bool active() const` | 查询 `m_active` |

#### 受保护接口

| 函数 | 说明 |
|------|------|
| `static void _bind_methods()` | Godot 方法绑定：`on_character_position_changed`、`on_player_spawn_projectile` |
| `void on_player_spawn_projectile(godot::Node* obj)` | 玩家射击信号槽：从 `ProjectileSpawner` 取子弹，对齐 `FiringPoint`，`add_child` |
| `void on_character_position_changed(...)` | 控制器位置变化调试输出到 Console |

#### 私有接口（本次新增）

| 函数 | 说明 |
|------|------|
| `void spawn_player_at_marker()` | 查找 `SpawnPoint` 标记，将 `m_player` 移到其全局坐标 |
| `void spawn_enemies_from_markers()` | 扫描名称以 `EnemySpawn` 开头的直接子 `Marker2D`，实例化 `Enemy` 并定位 |

#### 成员变量

| 成员 | 说明 |
|------|------|
| `m_active` | 原子布尔，关卡是否激活（控制光标与绘制） |
| `m_background` | 背景节点指针（预留，当前未在 cpp 中使用） |
| `m_projectile_spawner` | 子弹生成器，`_ready` 时 `add_child` |
| `m_player` | 运行时实例化的玩家指针 |
| `m_physics_box` | `DebugZones/PhysicsBox` 的 `RigidBody2D` 引用（预留调试） |

#### 前向声明

| 类型 | 说明 |
|------|------|
| `godot::RigidBody2D` | `m_physics_box` 类型，减少头文件 include |
| `rl::Player` | 玩家类前向声明 |

## 3. `src/entity/level.cpp`

**文件含义**：`Level` 全部方法实现。本次核心变更在 `_ready` 初始化顺序，以及两个刷点私有方法的实现。

### 函数说明（按调用顺序）

#### 构造与生命周期

| 函数 | 说明 |
|------|------|
| `Level::Level()` | `scene::node::set_unique_name(this, name::level::level1)`；`activate(true)` |
| `Level::_ready()` | 见下方步骤表 |
| `Level::_process(delta_time)` | 编辑器中跳过；根据 `active()` 切换光标显隐；`queue_redraw()` |
| `Level::_draw()` | `active()` 时在全局鼠标位置画半径 5 的 `DARK_CYAN` 圆 |
| `Level::activate(active)` | 写入 `m_active` |
| `Level::active()` | 返回 `m_active` |
| `Level::_bind_methods()` | 绑定两个 `[[signal_slot]]` 成员函数 |

**`Level::_ready()` 执行步骤**

| 步骤 | 代码行为 |
|------|----------|
| 1 | `find_child(physics_box, recursive=true)` → `m_physics_box` |
| 2 | 预加载 `player.tscn`，`instantiate()` → `m_player` |
| 3 | `set_controller(memnew(PlayerController))` |
| 4 | `add_child(m_player)` |
| 5 | **`spawn_player_at_marker()`**（L01 新增） |
| 6 | `add_child(m_projectile_spawner)` |
| 7 | **`spawn_enemies_from_markers()`**（L01 新增） |
| 8 | 连接 `position_changed`、`spawn_projectile` 信号 |

#### 刷点逻辑（本次新增）

| 函数 | 说明 |
|------|------|
| `spawn_player_at_marker()` | ① `m_player == nullptr` 则返回；② `find_child(spawn_point)`；③ 转为 `Marker2D`；④ `set_global_position(marker->get_global_position())` |
| `spawn_enemies_from_markers()` | ① 预加载 `enemy.tscn`；② 遍历 `Level` 直接子节点；③ 名称 `begins_with("EnemySpawn")`；④ 转为 `Marker2D`；⑤ `instantiate()` 敌人；⑥ 对齐标记全局坐标；⑦ `add_child(enemy)` |

**`spawn_enemies_from_markers` 匹配规则**

| 节点名 | 是否生成敌人 |
|--------|----------------|
| `EnemySpawn1` | ✅ |
| `EnemySpawn2` | ✅（若将来添加） |
| `SpawnPoint` | ❌ 前缀不匹配 |
| `Boundaries` | ❌ 非 `Marker2D` |

> B04 将在本函数内为每个 `Enemy` 追加 `EnemyController` 挂载。

#### 信号槽（既有，L01 未改语义）

| 函数 | 说明 |
|------|------|
| `on_player_spawn_projectile(obj)` | `m_projectile_spawner->spawn_projectile()`；从 `obj`（`FiringPoint`）取全局位置/旋转；`add_child(projectile)` |
| `on_character_position_changed(node, location)` | Console 打印节点类名与坐标（调试用） |

### Include 依赖（本文件）

| 头文件 | 用途 |
|--------|------|
| `entity/character/enemy.hpp` | `spawn_enemies_from_markers` 实例化敌人（L01 新增） |
| `entity/character/character.hpp` | 信号连接 `CharacterController` |
| `entity/controller/player_controller.hpp` | 玩家控制器类型 |
| `singletons/console.hpp` | 位置调试输出 |
| `util/scene.hpp`（经 level.hpp） | `resource::preload::packed_scene` |

## 4. `project/scenes/levels/level1.tscn`（场景资源）

**文件含义**：第一关 Godot 场景资源，根节点类型为 C++ 扩展类 `Level`。定义可视地面、碰撞边界、出生/刷点标记与调试区域。无附加脚本，逻辑由 `Level` C++ 驱动。

### 子资源（SubResource）

| ID | 类型 | 参数 | 用途 |
|----|------|------|------|
| `RectangleShape2D_wall_h` | `RectangleShape2D` | size `2040×40` | 上下墙碰撞形状 |
| `RectangleShape2D_wall_v` | `RectangleShape2D` | size `40×1540` | 左右墙碰撞形状 |
| `OccluderPolygon2D_d0buj` | `OccluderPolygon2D` | 1024×1024 方形 | 调试区光照遮挡 |

### 节点说明

| 节点路径 | 类型 | 关键属性 | 说明 |
|----------|------|----------|------|
| `Level1` | `Level` | — | C++ 关卡根；`Main` 实例化入口 |
| `Ground` | `ColorRect` | offset ±1000/±750 | 森林绿地面，`z_index=-10` |

| `Boundaries` | `Node2D` | — | 围墙分组，无碰撞 |

| `DebugZones` | `Node2D` | pos `(-750,500)` | 调试区分组 |

## 6. 运行时数据流

```
Main 构造
  → preload Level1.tscn → instantiate Level
  → CanvasLayer.add_child(Level)

Level::_ready
  → instantiate Player + PlayerController
  → add_child(Player)
  → spawn_player_at_marker()     // 读取 SpawnPoint
  → add_child(ProjectileSpawner)
  → spawn_enemies_from_markers() // 读取 EnemySpawn*
  → connect spawn_projectile → on_player_spawn_projectile

玩家 WASD 移动
  → Character::move_and_slide
  → 与 Boundaries/Wall* (layer 8) 碰撞阻挡

玩家射击
  → on_player_spawn_projectile
  → Projectile 加入 Level 子树
```
