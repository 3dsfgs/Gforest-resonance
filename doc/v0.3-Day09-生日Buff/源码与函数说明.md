# v0.3 Day09 源码与函数说明

## 1. 流程

```
Main 启动
  C++ Main::_ready → 仅默认设置（不 load_room）
  GDScript main.gd → 实例化 birthday_gate.tscn
    测算 → 写 user://profile.json
    进入森林 → Main.begin_run() → load_room(0)
  Level::_ready → birth_buff::apply_from_disk(player, spawner)
```

切房 / 重开仍 `load_room`，每次新 Player 都会再读 profile 套 buff，再 `apply_player_hearts(carry)`。

## 2. 数据

| 文件 | 用途 |
|------|------|
| `res://data/buff_rules.json` | 6 条命格 + buff 数值 |
| `user://profile.json` | 玩家上次生日与命格结果 |

`profile.json` 字段：`year/month/day/fate_id/title/desc/buff_summary/buffs{...}`。

## 3. GDScript

- `project/scripts/birthday_gate.gd`：UI + 选命格 + 写档  
- `project/scripts/main.gd`：启动挂生日门  
- 选格：`absi((month * 31 + day) % rules.size())`

## 4. C++

| 符号 | 作用 |
|------|------|
| `Main::begin_run()` | 生日确认后进房 1 |
| `birth_buff::load_profile` | 读 `user://profile.json` |
| `birth_buff::apply` | `set_max_hearts` / `set_movement_speed` / `set_fire_rate` |
| `Level::_ready` | 刷完玩家与 Spawner 后 `apply_from_disk` |

基数：血量 5、移速 500、射速 `combat::projectile_fire_rate`。

## 5. 调参

| 目标 | 改哪里 |
|------|--------|
| 文案 / 哪条命格对应什么 buff | `buff_rules.json` |
| 映射算法 | `birthday_gate.gd` → `_pick_rule` |
| 默认基数 | `birth_buff.cpp` 内 `base_*` |
