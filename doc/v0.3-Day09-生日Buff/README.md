## 概述

本地版「八字」情感内核（**不调 API**）：

1. 启动弹出生日门 → 输入年/月/日  
2. **测算命格** → 显示标题 + 治愈文案 + 加成摘要  
3. **进入森林** → 写入 `user://profile.json` → `Main.begin_run()` 进房 1  
4. C++ 每房刷玩家时读 profile，套用 **血量 / 移速 / 射速**

映射规则：`(month * 31 + day) % 6` → 6 条命格之一（同年同月同日结果稳定）。

---

## 六条命格

| id | 命格 | 可感知加成 |
|----|------|------------|
| `humble_roots` | 出身寒微 | 血量 +1 · 移速略降 |
| `lone_blade` | 孤军奋战 | 射速提升 · 血量 -1 |
| `still_waters` | 静水深流 | 移速提升 |
| `slow_bloom` | 厚积薄发 | 血量 +1 · 射速略降 |
| `toward_light` | 向光而行 | 移速与射速小幅提升 |
| `bend_and_rise` | 能屈能伸 | 射速提升 · 移速略降 |

文案与数值在 `project/data/buff_rules.json`，可直接改。
