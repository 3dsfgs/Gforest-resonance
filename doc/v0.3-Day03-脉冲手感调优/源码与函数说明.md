## 2. `Projectile` 反弹与朝向

### `_ready`

- `PhysicsMaterial`：`bounce` / `friction` 来自常量  
- `apply_impulse(forward * m_velocity)`，`m_velocity` 默认 = `projectile_impulse`

### `_integrate_forces`

| 标志 | 行为 |
|------|------|
| 首次有速度 | 记录 `m_flight_speed` |
| `m_pending_bounce_realign` | 把线速度方向单位化 × `m_flight_speed`，并 `set_rotation(dir.angle())` |
| 平时 | `sync_facing_to_velocity`：刚体朝向 = 速度角 |

> 子节点 `Bullet` Sprite 仍保留相对旋转 `π/2`（贴图朝上对齐刚体 X 轴），与发射时一致。

### `on_body_entered`（墙 / PhysicsObjects）

```text
bounce_count >= max  → queue_free
否则                 → count++，记 bounce_point，开玩家 mask，pending_realign = true
```

敌人命中、反弹自伤逻辑与 P0-B03 / Day2 相同。

## 4. `Level::on_player_spawn_projectile`

```cpp
rotation = firing_pt.rotation + randf_range(-spread, +spread)
```

`spread = projectile_spread_radians`；为 `0` 时无抖动。

## 6. 调参指南

| 手感问题 | 改什么 |
|----------|--------|
| 射太密/太疏 | `projectile_fire_rate` |
| 飞太快/太慢 | `projectile_impulse` |
| 散射太大/太小 | `projectile_spread_radians` |
| 反弹后仍偏慢 | 检查 `m_flight_speed` 是否捕获；或略提高 `projectile_physics_bounce` |
| 不要反弹 | 把 `projectile_max_wall_bounces` 设为 `0`（一撞墙就销毁） |
| 允许多弹 | 提高 `projectile_max_wall_bounces`（需再评估自伤半径） |
| 换贴图 | 改 `bullet.tscn` 的 `texture` |
