# v0.3 Day07–08 源码与函数说明

## 1. 输入流

```
空格/Shift → InputMap "dash"
  → PlayerController::process_action_input (just_pressed)
  → signal character_dash
  → Player::on_character_dash
```

## 2. `Player::on_character_dash`

前置：存活、未在冲刺中、冷却结束。

1. `resolve_dash_direction()`：优先 `m_last_move_dir`，否则 `Vector2(0,-1).rotated(rotation)`
2. 设 `m_dash_remaining` / `m_dash_cooldown_remaining`
3. 保存并改 `collision_mask` → 仅 `walls_layer`（穿怪）
4. `start_invincibility(dash_invincibility_duration)`
5. `combat_feedback::play_player_dash`

## 3. `Player::on_character_movement`（覆盖）

- 记录非零输入到 `m_last_move_dir`
- 冲刺中：跳过走路摩擦 lerp，直接 `translate(dir * speed * mult * dt)` + `move_and_slide`
- 否则：调用 `Character::on_character_movement`

## 4. 无敌时长

`Character::start_invincibility(duration)`：

- `duration <= 0` → 用受击默认 `invincibility_duration`（1.0s）
- 新时长**不会缩短**已有更长窗口（冲刺 0.22 不会砍掉受击 1.0）

## 5. HUD

`HeartHud::_process` 每帧读 `Player::get_dash_ready_ratio()`（1=就绪，0=刚放完），在心形下画填充条。

## 6. 调参速查

| 目标 | 改哪里 |
|------|--------|
| 冲更远 | ↑ `dash_speed_mult` 或 `dash_duration` |
| 冷却更快 | ↓ `dash_cooldown` |
| 无敌更长 | ↑ `dash_invincibility_duration` |
| 换音效 | `path::audio::player_dash` |
| 降级瞬移 | 在 `on_character_dash` 里 `set_global_position(+ dir * distance)`，可去掉持续位移 |
