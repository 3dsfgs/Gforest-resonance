## 概述

P0 目标：消除「一眼原型」的四处硬伤，让基础手感与呈现「不再奇怪」。表达层不降级。

| # | 任务 | 借鉴 | 状态 |
|---|------|------|------|
| P0-1 | 心灯 HUD（心形多边形替换 `draw_circle`） | 以撒 | ✅ |
| P0-2 | 相机阻尼 + 鼠标前瞻 | Gungeon / Hades | ✅ |
| P0-3 | 敌人入场预警圈 0.4s → 淡入 | Nuclear Throne | ✅ |
| P0-4 | 房间过场：黑屏淡入淡出 + 地名卡 | Hades / 元气骑士 | ✅ |

> 叙事语义：森林 = 梦境/心象；战斗 = 梦中推开暗影心魔；血量 = 心灯；攻击 = 光。房链情绪三幕：**雾缘（冷暗）→ 深心（透光）→ 光扉（暖金 + Boss）**。

## 各项要点

### P0-1 心灯 HUD
- `heart_hud.cpp` 用 10 点心形多边形 `draw_colored_polygon` + 描边，替换原 `draw_circle`。
- 填充偏暖金（呼应「心灯」）。

### P0-2 相机阻尼 + 鼠标前瞻
- `Camera` 启用 `position_smoothing`，并按鼠标方向做前瞻 lerp。
- 屏震（trauma）与前瞻合并进 `set_offset()`，互不打架。

### P0-3 敌人入场预警圈 + 淡入
- 刷怪不再瞬间 pop：先入队 `PendingEnemySpawn`，画 0.4s 暖金预警圈（圆 + 描边环），到时再生成敌人并从 `alpha=0` 淡入。

### P0-4 房间过场 + 地名卡
- 清房后 C++ 不直接切房，改为发信号 `room_advance_requested(next_index, hearts, room_name)`。
- `room_transition.gd`：**淡入黑屏 → 地名卡（+ 情绪短句）→ `advance_to_room()` → 淡出**。
- 地名对应三幕：`深心`「越往里，影越深。」`光扉`「最后一道影，像你自己。」（首房「雾缘」由 `begin_run()` 直接进入，不过场。）

## 走测中发现并修复的问题

| 问题 | 根因 | 修复 |
|------|------|------|
| 界面跳转/叙事**中文乱码** | C++ 中文 `const char*` 按 latin-1 构造 `godot::String` | 改用 `String::utf8()`（地名卡 + 失败叙事） |
| 鼠标移出画面时**小人仍跟随** | 玩家 Controller 默认常启用，不受画面焦点门控 | `Level::activate()` 联动：鼠标离开画面暂停玩家输入，移回恢复（仅游玩状态） |
| 画面内**看不到攻击准星** | P0-3 误删了 `_draw` 里充当准星的调试圆点，系统光标又被隐藏 | 恢复并美化为「光」主题准星（暖金环 + 亮心 + 四道光刺） |
