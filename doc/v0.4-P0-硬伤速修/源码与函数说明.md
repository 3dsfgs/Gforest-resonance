## 3. P0-2 相机（`src/entity/camera.hpp` / `camera.cpp`）

| 函数 | 说明 |
|------|------|
| 构造 | `set_position_smoothing_enabled(true)` + `position_smoothing_speed` |

## 4. P0-3 敌人预警 + 淡入（`src/entity/level.*`）

数据结构（`level.hpp` 私有）：

```
struct PendingEnemySpawn { Vector2 position; bool is_brute; double delay_remaining; };
struct FadingEnemy       { Enemy* enemy; double fade_remaining; };
std::vector<PendingEnemySpawn> m_pending_spawns;
std::vector<FadingEnemy>       m_fading_enemies;
```

| 函数 | 说明 |
|------|------|
| `spawn_enemies_from_markers()` | 不再瞬时生成；遍历 Marker 入队 `queue_enemy_spawn` |
| `queue_enemy_spawn(pos, is_brute)` | push `PendingEnemySpawn` + `queue_redraw` |
| `update_pending_spawns(delta)` | 递减 `delay_remaining`，到时移出并 `finalize_enemy_spawn` |
| `finalize_enemy_spawn(pending)` | 实例化敌人、`modulate.a=0`、接信号、push 到 `m_fading_enemies`、`++m_enemy_count` |
| `update_fading_enemies(delta)` | 递增 alpha 至 1；节点失效（`!is_inside_tree()`）则剔除 |
| `_draw()` | 对每个 pending 画预警圈：`draw_circle`(淡填充) + `draw_arc`(描边环) |
| `clear_enemies()` | 同时清空 pending / fading 容器 |

> `draw_arc` 的整圆角度用字面量 `6.2831855f`（godot-cpp 此版本无 `Math::TAU`/`Math::PI` 常量）。

## 5. P0-4 房间过场

### C++（`src/main.*`）

| 函数 | 说明 |
|------|------|
| `on_room_cleared(index)` | 不再直接 `load_room`；计算 `next_index`、越界保护后 emit `room_advance_requested(next_index, hearts, utf8(room_name))` |
| `advance_to_room(index, hearts)` | 供 GDScript 过场播完回调，内部 `load_room` |

`_bind_methods` 中绑定 `advance_to_room` 与信号 `room_advance_requested<int,int,String>`。

### GDScript（`project/scripts/`）

- `main.gd`：`_ready` 连接 `room_advance_requested → _on_room_advance_requested`，实例化 `room_transition.gd`（命名 `RoomTransition`，防重入）。
- `room_transition.gd`：`setup(main, next_index, hearts, room_name)` → `_play()`：
  1. 黑屏 `color:a 0→1`（FADE_OUT）
  2. 地名 + 情绪短句淡入（CARD_IN）
  3. 停留（CARD_HOLD）→ `_load_next_room()` 调 `advance_to_room`
  4. 黑屏 `a→0`（FADE_IN）→ `queue_free`
