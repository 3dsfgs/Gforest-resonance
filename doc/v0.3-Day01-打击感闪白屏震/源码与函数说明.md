# v0.3 Day01 源码与函数说明

本文档逐文件说明 Day01「打击感 — 闪白 / 屏震 / 手感修订」涉及的类、函数与调用链。

---

## 1. `src/core/constants.hpp`（`combat` 命名空间增量）

### 受击闪色

```cpp
constexpr inline double hit_flash_duration{ 0.12 };
constexpr inline float enemy_hit_flash_r{ 4.0f };
constexpr inline float enemy_hit_flash_g{ 5.0f };
constexpr inline float enemy_hit_flash_b{ 5.5f };
constexpr inline float player_hit_flash_r{ 5.0f };
constexpr inline float player_hit_flash_g{ 1.4f };
constexpr inline float player_hit_flash_b{ 1.1f };
```

- `modulate` 的 RGB 可大于 1.0，Godot 会按高亮处理，形成「闪一下」效果。
- 敌人默认走 `Character::hit_flash_color()`；玩家由 `Player::hit_flash_color()` 覆盖。

### 屏震

```cpp
constexpr inline float hit_shake_trauma{ 0.7f };
constexpr inline float camera_shake_max_offset{ 22.0f };
constexpr inline float camera_shake_decay{ 2.0f };
```

### 无敌帧（相对 P0-B02 的修订）

| 常量 | P0-B02 原值 | Day01 修订 |
|------|-------------|------------|
| `invincibility_duration` | `0.75` | `1.0` |
| `invincibility_blink_interval` | `0.08` | `0.1` |
| `invincibility_blink_alpha` | `0.35` | `0.25` |

## 2. `src/entity/camera.hpp` / `camera.cpp`

### 类 `Camera : public godot::Camera2D`

| 成员/方法 | 说明 |
|-----------|------|
| `m_trauma` | 当前震动强度，钳制在 `[0, 1]` |
| `add_trauma(float amount)` | 累加 trauma 并 `set_process(true)` |
| `_process(double delta_time)` | trauma 按 `camera_shake_decay` 衰减；offset = `max_offset * trauma² * random` |

**设计要点**：

- 使用 **trauma²** 使小幅震动更柔和，大幅震动仍有冲击。
- 仅当 `m_trauma > 0` 时处理；归零后 `set_offset(0)` 并 `set_process(false)`。
- 构造函数中 `set_process(false)`，与 P0 相机默认行为一致。

## 3. `src/entity/character/character.hpp` / `character.cpp`

### 新增虚函数

| 函数 | 默认实现 | `Player` 覆盖 |
|------|----------|---------------|
| `bool owns_active_camera() const` | `false` | `true` |
| `godot::Color hit_flash_color() const` | 青白 `(enemy_hit_flash_*)` | 红橙 `(player_hit_flash_*)` |

### `_ready()` 变更

```cpp
this->add_child(m_camera);
if (owns_active_camera())
    m_camera->make_current();
```

敌人仍挂载 `Camera` 子节点（与场景/模板一致），但**不**设为 current，避免抢走玩家镜头。

### `take_damage()` 反馈链

```
apply_damage 成功
  → emit_hearts_changed()
  → if (owns_active_camera()) m_camera->add_trauma(...)   // 仅玩家
  → if (仍存活) start_hit_flash() + start_invincibility() // bypass 时跳过无敌
  → if (死亡) end_invincibility() + emit died
```

### 受击闪与无敌视觉：`update_damage_visual()`

优先级：

1. `m_hit_flash_remaining > 0` → `set_modulate(hit_flash_color())`
2. 否则若无敌且暗相 → `alpha = invincibility_blink_alpha`
3. 否则 → 完全不透明 `(1,1,1,1)`

### `_process()` 合并逻辑

- 递减 `m_hit_flash_remaining`
- 无敌期间递减 `m_invincibility_remaining` 并切换 `m_blink_visible`
- 每帧调用 `update_damage_visual()`
- 当闪与无敌均结束 → `end_invincibility()` 并 `set_process(false)`

### 成员 `m_hit_flash_remaining`

受击高亮倒计时；与无敌计时独立，允许「先红闪 → 再半透明闪烁」两阶段反馈。

## 4. `src/entity/character/player.hpp` / `player.cpp`

```cpp
bool owns_active_camera() const override { return true; }

godot::Color Player::hit_flash_color() const
{
    return godot::Color(combat::player_hit_flash_r, combat::player_hit_flash_g,
                        combat::player_hit_flash_b, 1.0f);
}
```

`Player::_ready()` 仍先调用 `Character::_ready()`，由基类完成 `make_current()`。

## 5. 调用链示例

### 子弹打中敌人

```
Projectile::on_body_entered
  → Enemy::take_damage(projectile_damage_hearts)
    → owns_active_camera() == false  → 不 add_trauma
    → start_hit_flash()              → 青白闪
```

### 敌人碰到玩家

```
Player::process_slide_collisions
  → take_damage(enemy_contact_damage_hearts)
    → owns_active_camera() == true   → add_trauma
    → start_hit_flash()              → 红橙闪
    → start_invincibility()          → 1.0s 闪烁
```

## 6. 设计决策记录

| 决策 | 理由 |
|------|------|
| 屏震只在 `owns_active_camera()` 时触发 | 语义清晰，不依赖「谁是 current」的隐式副作用 |
| 敌人仍保留 Camera 子节点 | 少改场景结构；未来可做敌人特写或取消子节点 |
| 闪色用虚函数而非 `dynamic_cast` | 扩展 Enemy 子类时可再覆盖 |
| 修订无敌参数而非单独加「玩家无敌 UI」 | Day1 范围控制；HUD 提示可放 Day2+ |

## 8. 调参指南

在 `src/core/constants.hpp` 的 `combat` 命名空间中修改，改后需重新 `configure-and-build`。

| 手感问题 | 建议调整 |
|----------|----------|
| 震得太猛 | 减小 `camera_shake_max_offset` 或 `hit_shake_trauma` |
| 震完收不住 | 增大 `camera_shake_decay` |
| 红闪太刺眼 | 降低 `player_hit_flash_r`，或略提高 g/b |
| 打中敌人不够明显 | 提高 `enemy_hit_flash_*` 或 `hit_flash_duration` |
| 无敌仍感觉短 | 增大 `invincibility_duration`（如 1.2） |
| 无敌闪烁看不清 | 降低 `invincibility_blink_alpha` 或增大 `invincibility_blink_interval` |
