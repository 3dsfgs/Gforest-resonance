# MVP 定义与验收标准

> **版本**：Demo v0.1（P0 收尾）
> **目标**：自己能玩的几分钟闭环，不上线、不要求美术终稿。
> **关联**：[开发排期与里程碑](./开发排期与里程碑.md) · [任务/P0-战斗与角色](./任务/P0-战斗与角色.md) · **[任务/P0-MVP最小闭环开发任务](./任务/P0-MVP最小闭环开发任务.md)**

---

## 1. MVP 一句话

玩家在**一张森林关卡**中，以**俯视角**移动、用**脉冲**射击击败**至少一种敌人**，承受**心形血量**伤害，**死亡后可重开**，完成**一次简短结算**。

---

## 2. 范围内（Must Have）

| # | 功能 | 验收标准 |
|---|------|----------|
| M1 | 俯视角移动 | WASD 移动流畅；鼠标控制朝向 |
| M2 | 脉冲攻击 | 按键射击；子弹命中造成伤害 |
| M3 | 心形血量 | 3 或 5 颗心；受击扣心 + 无敌帧；UI 可见 |
| M4 | 敌人 | 至少 1 种小怪；能追击；可被击杀 |
| M5 | 玩家死亡 | 血量归零 → 重开本关 |
| M6 | 单张关卡 | 1 个可探索区域（占位 TileMap 可） |
| M7 | 胜负闭环 | 清敌或到出口 → 结算文字 |
| M8 | 可构建运行 | configure-and-build 通过；F5 能启动 |

---

## 3. 范围外（Won't Have in v0.1）

| 功能 | 计划阶段 |
|------|----------|
| 赛博八字 API | P1 |
| 极地斩 / 能量之光 / 天使之翼 | P1 |
| 召唤 / 融合 | P2 |
| 生日彩蛋 / 图鉴 | P2 |
| 存档 | P1 起；v0.1 可无 |
| AI 美术终稿 | P0 末或 P1 |
| Boss / 多关卡 | P1–P2 |

---

## 4. 体验指标

| 指标 | 目标 |
|------|------|
| 单次可玩时长 | 3–5 分钟 |
| 崩溃 | 全流程 0 崩溃 |
| 帧率 | 1080p 稳定 60 FPS |

---

## 5. 降级方案

| 风险 | 降级 |
|------|------|
| 森林美术未完成 | 色块 + 两层 Parallax |
| 敌人 AI 复杂 | 直线追击 |
| 结算 UI 未完成 | Console RichText 输出 |
| 对象池未完成 | ≤5 敌直接 instantiate |

## 6. 演示检查清单

- [ ] 启动到进关卡 < 30 秒

- [ ] 敌人受伤、死亡有反馈
- [ ] 受击扣心、无敌帧生效
- [ ] 死亡可重开
- [ ] 通关/死亡有文字反馈
- [ ] 连续 3 轮无崩溃
