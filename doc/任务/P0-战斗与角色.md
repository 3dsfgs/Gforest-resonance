# P0 任务：战斗与角色

## 任务列表

### P0-B01 心形血量系统

| 项 | 内容 |
|----|------|
| **目标** | 3 或 5 颗心；受击扣减；无传统血条 |
| **依赖** | 无 |
| **预估** | 2–3 天 |
| **主要文件** | `src/entity/character/character.hpp/cpp`，新建 `health` 相关或内联成员 |
| **验收** | 受击扣 1 心；UI 同步；心为 0 触发死亡信号 |
| **降级** | 先用 Label 显示 `❤️×N` |

---

### P0-B02 受击无敌帧

| 项 | 内容 |
|----|------|
| **目标** | 受击后 0.5–1s 无敌，闪烁反馈 |
| **依赖** | P0-B01 |
| **预估** | 1–2 天 |
| **验收** | 无敌期间不重复扣心 |
| **降级** | 无闪烁，仅逻辑无敌 |

---

### P0-B03 脉冲攻击打磨

| 项 | 内容 |
|----|------|
| **目标** | 基于现有 Projectile；伤害数值；命中反馈 |
| **依赖** | 无（可与 B01 并行） |
| **预估** | 2 天 |
| **主要文件** | `projectile.*`，`player_controller.cpp`，`level.cpp` |
| **验收** | 射击、命中、敌人扣血流畅 |
| **降级** | 无命中特效，仅扣血 |

---

### P0-B04 敌人基础 AI

| 项 | 内容 |
|----|------|
| **目标** | 1 种小怪：发现玩家 → 追击 → 接触伤害 |
| **依赖** | P0-B01 |
| **预估** | 2–3 天 |
| **主要文件** | `enemy.*`，`enemy_controller.cpp` |
| **验收** | 敌人可击杀；接触对玩家造成伤害 |
| **降级** | 不巡逻，仅朝玩家移动 |

---

### P0-B05 死亡与重开

| 项 | 内容 |
|----|------|
| **目标** | 玩家死亡 → 暂停输入 → 重开当前关卡 |
| **依赖** | P0-B01，P0-L02（关卡） |
| **预估** | 1–2 天 |
| **主要文件** | `level.cpp`，`main.cpp` 或 GDScript 重开按钮 |
| **验收** | 死亡后 5 秒内可再玩 |
| **降级** | 重开 = 重新加载 Level 场景 |

---

### P0-B06 伤害与碰撞层整理

| 项 | 内容 |
|----|------|
| **目标** | 统一 LayerID；玩家/敌人/子弹碰撞矩阵 |
| **依赖** | P0-B03，P0-B04 |
| **预估** | 1 天 |
| **主要文件** | `core/constants.hpp`，场景碰撞层 |
| **验收** | 子弹不打自己；敌人碰玩家扣心 |
