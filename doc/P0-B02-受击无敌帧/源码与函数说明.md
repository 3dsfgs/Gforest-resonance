## 2. `src/entity/character/character.hpp`

**文件含义**：可控角色基类声明。本次在 P0-B01 血量 API 之上扩展无敌查询、扣血绕过参数、帧更新与闪烁相关受保护方法及成员。

### 类：`class Character`

#### 公开接口（本次新增或变更）

| 函数 | 说明 |
|------|------|
| `void _process(double delta_time) override` | 无敌倒计时与闪烁相位更新；非无敌时早退并清理状态 |
| `bool is_invincible() const` | 当前是否处于无敌状态（`m_invincibility_remaining > 0`） |
| `bool take_damage(int hearts = 1, bool bypass_invincibility = false)` | 扣心入口；无敌时默认拒绝；成功且仍存活则启动无敌（除非 bypass） |

#### 受保护接口（本次新增）

| 函数 | 说明 |
|------|------|
| `void start_invincibility()` | 重置计时器、开启 `_process`、刷新精灵透明度 |
| `void end_invincibility()` | 清零计时器、关闭 `_process`、恢复精灵完全不透明 |
| `void update_invincibility_visual()` | 根据无敌与闪烁相位设置 `PlayerSprite` 的 `modulate.a` |

#### 成员变量（本次新增）

| 成员 | 说明 |
|------|------|
| `godot::Sprite2D* m_sprite` | `_ready` 中缓存的精灵指针，闪烁视觉目标 |
| `double m_invincibility_remaining` | 剩余无敌时间（秒），降至 0 时结束无敌 |
| `double m_blink_timer` | 闪烁相位累计时间 |
| `bool m_blink_visible` | 当前闪烁相位：`true` 为不透明相，`false` 为半透明相 |

#### Godot 绑定（`_bind_methods` 内新增）

| 绑定 | 说明 |
|------|------|
| `bind_member_function(Character, is_invincible)` | 供调试或脚本查询无敌状态 |

#### 前向声明（本次新增）

| 类型 | 说明 |
|------|------|
| `godot::Sprite2D` | 避免在头文件中 include 完整 Godot 精灵头 |

## 3. `src/entity/character/character.cpp`

**文件含义**：`Character` 全部方法实现。本次核心变更在 `_ready`、`_process`、`take_damage` 及三个无敌辅助函数。

### 函数说明（按逻辑分组）

#### 初始化

| 函数 | 说明 |
|------|------|
| `Character::_ready()` | **变更**：`set_process(false)` 默认关闭帧处理；`find_child(sprite)` 缓存 `m_sprite` |

#### 血量与无敌

| 函数 | 说明 |
|------|------|
| `is_invincible()` | 返回 `m_invincibility_remaining > 0.0` |
| `take_damage(hearts, bypass_invincibility)` | ① 已死亡 → `false`；② 无敌且非 bypass → `false`；③ `apply_damage`；④ 广播 `hearts_changed`；⑤ 仍存活且非 bypass → `start_invincibility()`；⑥ 死亡 → `end_invincibility()` + `died` |
| `reset_hearts()` | **变更**：先 `end_invincibility()`，再回满血并广播 |

#### 帧更新与视觉

| 函数 | 说明 |
|------|------|
| `_process(delta_time)` | 递减 `m_invincibility_remaining`；每 `blink_interval` 翻转 `m_blink_visible` 并 `update_invincibility_visual()`；结束时 `end_invincibility()` |
| `start_invincibility()` | 设 `remaining = duration`；重置 blink 状态；`set_process(true)`；刷新视觉 |
| `end_invincibility()` | 清零所有无敌/blink 状态；`set_process(false)`；恢复 alpha = 1 |
| `update_invincibility_visual()` | `m_sprite` 为空则跳过；无敌且 `!m_blink_visible` 时 alpha = `blink_alpha`，否则 alpha = 1 |

#### 未改语义但相关的既有函数

| 函数 | 说明 |
|------|------|
| `on_character_movement` | 仍调用 `process_slide_collisions()`，伤害区检测时机不变 |
| `is_alive()` | 仍委托 `m_health.is_alive()` |
| `emit_hearts_changed()` | 行为未变 |
| `process_slide_collisions()` | 基类仍为空实现 |

## 4. `src/entity/character/player.cpp`（本次增量）

**文件含义**：玩家关卡危险区碰撞逻辑。本次仅调整 **DeathPit** 扣血调用方式。

### 函数说明

| 函数 | 变更说明 |
|------|----------|
| `handle_zone_contact(body)` | **DeathZones**：`take_damage(get_max_hearts(), true)` — 绕过无敌，即死；**DamageZones**：`take_damage(1)` — 尊重无敌 |
| `process_slide_collisions()` | 无变更；仍仅对首次进入的碰撞体调用 `handle_zone_contact` |
| 其余函数 | 无变更 |

### 危险区与无敌行为对照

| 区域 | 场景节点 | 碰撞层 | `take_damage` 调用 | 无敌 | 闪烁 |
|------|----------|--------|-------------------|------|------|
| 伤害区（绿） | `DamageZone` | `16` DamageZones | `take_damage(1)` | ✅ 触发 | ✅ 有 |
| 死亡区（红） | `DeathPit` | `32` DeathZones | `take_damage(max, true)` | ❌ 绕过 | ❌ 无（通常即死） |

## 5. 运行时调用链

### 进入绿区扣 1 心并闪烁

```
PlayerController → character_move
  → Character::on_character_movement
    → move_and_slide()
    → Player::process_slide_collisions
      → handle_zone_contact (DamageZone)
        → Character::take_damage(1)
          → start_invincibility()
          → emit hearts_changed
  → Character::_process (每帧，持续 0.75s)
    → update_invincibility_visual()  // modulate 闪烁
  → end_invincibility()  // 计时结束
```

### 无敌期间再次受击（被拦截）

```
任意来源 → take_damage(1)
  → is_invincible() == true
  → return false（不扣心、不重启无敌）
```

### 踩红区即死

```
handle_zone_contact (DeathPit)
  → take_damage(get_max_hearts(), true)
    → bypass 无敌检查
    → apply_damage(5)
    → end_invincibility()
    → emit died
```

### 回满血（调试 / 未来重生）

```
reset_hearts()
  → end_invincibility()   // 停止闪烁、关闭 _process
  → m_health.reset()
  → emit hearts_changed
```

```cpp
    /** 无敌闪烁相位切换间隔（秒）。 */
```

### `character.hpp`

```cpp
/**
 * 每帧回调：无敌倒计时与精灵闪烁。
 * 默认由 start_invincibility 开启，end_invincibility 关闭。
 */
void _process(double delta_time) override;

/** @return 是否处于受击无敌状态。 */
[[nodiscard]] bool is_invincible() const;

/**
 * 扣除若干颗心。
 * @param hearts 扣除心数，默认 1。
 * @param bypass_invincibility 为 true 时忽略无敌（如 DeathPit 即死）。
 * @return 是否实际扣除了心数。
 * 成功且仍存活时启动无敌；归零时 end_invincibility 并广播 died。
 */
bool take_damage(int hearts = 1, bool bypass_invincibility = false);

/** 进入无敌：重置计时、开启 _process、开始闪烁。 */
void start_invincibility();

/** 结束无敌：清零状态、关闭 _process、恢复精灵不透明。 */
void end_invincibility();

/** 根据无敌与闪烁相位更新 PlayerSprite 的 modulate 透明度。 */
void update_invincibility_visual();

/** 受击闪烁目标；_ready 中按 name::character::sprite 查找。 */
godot::Sprite2D* m_sprite{ nullptr };

/** 剩余无敌时间（秒）。 */
double m_invincibility_remaining{ 0.0 };

/** 闪烁相位计时器（秒）。 */
double m_blink_timer{ 0.0 };

/** 闪烁相位：true = 不透明相，false = 半透明相。 */
bool m_blink_visible{ true };
```

### `player.cpp`（`handle_zone_contact` 行为注释）

```cpp
/**
 * 根据碰撞层处理关卡危险区。
 * - DeathZones：take_damage(max, true)，绕过无敌，立即清空心数。
 * - DamageZones：take_damage(1)，受无敌帧保护。
 */
void handle_zone_contact(godot::PhysicsBody2D* body);
```

## 8. 调参与扩展建议

| 需求 | 修改位置 |
|------|----------|
| 无敌更长/更短 | `combat::invincibility_duration` |
| 闪烁更快/更明显 | `invincibility_blink_interval` / `invincibility_blink_alpha` |
| 敌人也闪烁 | 敌人场景添加同名 `PlayerSprite` 或改为查找首个 `Sprite2D` |
| 即死区也走无敌 | 去掉 `player.cpp` 中 `take_damage(..., true)` 的第二个参数 |
