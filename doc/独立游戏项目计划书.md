## 项目愿景

这是一款兼具**理性逻辑、个人感悟与艺术光影**的单人解压治愈系游戏。

通过极简的俯视角玩法与高表现力的光影氛围，塑造主人公直面困境、坚韧回弹的形象，给深夜疲惫的玩家以温暖和力量。叙事不是简单的心灵鸡汤——希望玩家在沉静游玩一段时间后，能体会主人公的不易，继而恢复自己的精气神。

**当前阶段目标**：先做出**自己能玩的内部 Demo**，不上线、不盈利、不宣发。

**长期主旨（非首版必达）**：正向反馈从游戏带入现实，类似《头号玩家》《创：战纪》的情感联结——知道理想化，仍愿尝试。

## 一、项目定位与设计哲学

| 维度 | 设计设定 | 备注 |
|------|----------|------|
| **游戏类型** | 单人 2D 俯视角动作探索（PVE） | 基于 `godot-roguelite` 模板：WASD + 鼠标瞄准；**关卡结构参考《元气骑士》房间制**，节奏偏治愈慢叙事，非弹幕海 |
| **关卡结构** | 森林房间串联（清怪 → 开门 → 下一房） | v0.2：**单房模板**（`level1.tscn`）；P1：多房连通与房间图 |
| **视觉维度** | 2D 玩法 + 房内静态美术 + Shader 氛围 | 每房固定底图与雾 overlay；**不用大地图视差**；P1 森林雾、丁达尔光用 Shader |
| **画风基调** | 《凯尔经的秘密》+《星游记》 | 葱郁、灵性、神秘图腾的绿色森林 |
| **美术方案** | AI 绘图（GPT Image 等）+ Godot Shader / 粒子 | P0 可用占位素材；真接入 AI 管线放在 P0 末或 P1 |
| **输入** | 键盘 / 鼠标 / 手柄 | 模板已支持键鼠与手柄切换 |
| **商业模式** | 完全不盈利，为爱发电 | 个人作品，无内购、无广告 |
| **联机** | 远期可能 | 首版及 6 个月周期内不做 |

## 二、核心玩法闭环

**探索 + 战斗 + 解锁故事**，拒绝早期复杂化（背包系统等后置）。

```
输入生日 → 赛博八字 API → 属性 Buff → 森林房间探索 → 战斗/技能 → 关卡叙事 → （图鉴/彩蛋）
```

### 1. 基础机制

| 机制 | 说明 |
|------|------|
| **心形血量** | 3 或 5 颗 ❤️，无长血条；每次受击有清晰顿挫 + 无敌帧 |
| **「气」资源** | 收集消耗，驱动【天使之翼】等终极技能（P1 实现） |
| **本地生日** | 首次输入年月日，仅本地存储；生日当天触发温热彩蛋（P2） |
| **慢速叙事** | 结算/过关文字慢速浮现，配合治愈节奏（P1–P2） |

### 2. 六大技能（分阶段）

| 技能 | 阶段 | 说明 |
|------|------|------|
| **脉冲** | P0 | 远程光能波动；模板已有 `Projectile` 基础 |
| **极地斩** | P1 | 近战横扫，强顿挫与光影 |
| **能量之光** | P1 | 地面治疗/加速光环 |
| **天使之翼** | P1 | 消耗 3「气」，子弹时间 + 高爆发 |
| **召唤** | P2 | 森林守护灵协同作战 |
| **融合盔甲** | P2 | Shader 流光材质 + 粒子，不改骨骼 |

### 3. 赛博八字 Buff（情感核心）

- 玩家输入出生年月日（本地存储）
- 调用**赛博八字 API**，按返回字段映射游戏属性（移速、视野、防御、暴击等）
- 映射表可配置（JSON/YAML），便于调数值
- 哲学参考：邓艾「出身寒微不是耻辱，能屈能伸方为丈夫」
- **降级**：API 不可用时使用 Mock 数据 + 固定命格

示例方向（最终以 API 规则为准）：

| 命格倾向 | 限制 | 回弹 |
|----------|------|------|
| 出身寒微 | 移速↓、视野↓ | 防御↑、受击后怒火攻击翻倍 |
| 孤军奋战 | 无常规补给 | 血量越低暴击越高 |

## 三、技术方向（摘要）

详细见 [技术架构说明](./技术架构说明.md)。

| 项 | 选型 |
|----|------|
| 引擎 | Godot 4.5 + GDExtension (C++) |
| 代码库 | 基于 `godot-roguelite` 模板，`src/` 扩展 |
| 战斗/数值/Buff/API | C++ |
| 菜单、图鉴、叙事 UI | GDScript |
| 光影特效 | Godot Shader + GPUParticles2D |
| 性能 | 对象池、异步 ResourceLoader；主线程不做同步大块加载 |
| 额外图形库 | **暂不引入**；若未来需要底层 OpenGL，再通过 vcpkg 添加 |

## 四、开发周期（6 个月 · 单人）

详见 [开发排期与里程碑](./开发排期与里程碑.md)。

| 阶段 | 时间 | 主题 | 交付物 |
|------|------|------|--------|
| **P0** | 月 1–2 | 核心战斗骨架 | 内部 Demo **v0.1**（自己能玩） |
| **P1** | 月 3–4 | 技能 + 氛围 + 八字管线 | Demo **v0.5** |
| **P2** | 月 5–6 | 内容填充 + 情感 + 打磨 | Demo **v1.0**（自用，不上线） |

每月预留约 **3 天缓冲**。高难度功能均有**降级方案**（见各任务文档）。

## 五、与模板的继承关系

| 保留扩展 | 新建/改造 |
|----------|-----------|
| `Main` / `Level` / `MainDialog` | 心形血、死亡重开、关卡流程；**Level 演进为房间容器** |
| `Player` + `PlayerController` | 技能槽、「气」、受击反馈 |
| `Projectile` / `ProjectileSpawner` | 脉冲及后续弹道 |
| `Enemy` / `EnemyController` | 更多敌人行为 |
| `Console`、信号绑定工具 | 叙事输出 |
| CMake + vcpkg 构建 | 按需加 HTTP 库（八字 API） |
