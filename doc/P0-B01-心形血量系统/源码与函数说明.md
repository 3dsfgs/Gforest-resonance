# P0-B01 源码与函数说明

本文档逐文件说明本次 P0-B01 涉及的 **头文件职责**、**cpp 文件含义**，以及 **每个函数/成员** 的作用。

---

## 1. `src/entity/character/health.hpp`

**文件含义**：纯 C++ 数据结构，不依赖 Godot API。封装「整数颗心」的增减逻辑，供 `Character` 内联持有。

### 类型：`struct HeartHealth`

| 成员 / 函数 | 说明 |
|-------------|------|
| `int max_hearts` | 最大心数，默认 `5` |
| `int hearts` | 当前心数，默认与 `max_hearts` 相同 |
| `bool is_alive() const` | 当前心数是否大于 0 |
| `void reset()` | 将 `hearts` 恢复为 `max_hearts` |
| `void set_max(int max)` | 设置上限（至少 1）；若当前心数超过新上限则截断 |
| `int apply_damage(int amount = 1)` | 扣除心数；已死亡或 `amount <= 0` 时返回 0；否则返回实际扣除颗数 |

```cpp
/** Discrete heart-based health used by Character (P0-B01). */
struct HeartHealth { ... };
```

## 2. `src/entity/character/character.hpp`

**文件含义**：所有可控角色的基类（`CharacterBody2D`）。本次新增血量成员、公开查询接口、Godot 属性/信号绑定，以及供子类重写的碰撞后处理钩子。

### 类：`class Character`

#### 公开接口

| 函数 | 说明 |
|------|------|
| `Character()` | 构造函数；设置 `MOTION_MODE_FLOATING` |
| `void _ready() override` | 挂载相机、查找开火点、连接控制器信号 |
| `CharacterController* get_controller() const` | 获取输入/AI 控制器 |
| `void set_controller(CharacterController*)` | 设置控制器（由 Level 在实例化后注入） |
| `bool is_alive() const` | 是否仍有剩余心数 |
| `int get_hearts() const` | 当前心数 |
| `int get_max_hearts() const` | 最大心数 |
| `bool take_damage(int hearts = 1)` | 扣心；成功扣血时发 `hearts_changed`；心为 0 时发 `died`；已死亡返回 `false` |
| `void reset_hearts()` | 回满血并广播 `hearts_changed` |

#### 受保护接口

| 函数 | 说明 |
|------|------|
| `virtual void process_slide_collisions()` | `move_and_slide()` 后调用；基类空实现，由 `Player` 重写做伤害区检测 |
| `void emit_hearts_changed()` | 向 Godot 发射 `hearts_changed(current, max)` |
| `get/set_movement_speed` 等 | 原有移动属性（未改语义） |
| `set_hearts(int)` | 编辑器/调试直接设当前心数（钳制到 `[0, max]`） |
| `set_max_hearts(int)` | 设置上限并广播变化 |
| `on_character_movement` | 移动插值 + `move_and_slide` + `process_slide_collisions` |
| `on_character_rotate` | 平滑转向 |
| `on_character_shoot` | 发射 `spawn_projectile` 信号 |

#### 成员变量（本次新增）

| 成员 | 说明 |
|------|------|
| `HeartHealth m_health{}` | 心形血量数据 |

#### 信号绑定（`_bind_methods` 内新增）

| 信号 | 参数 |
|------|------|
| `hearts_changed` | `int current`, `int max` |
| `died` | 无 |

## 3. `src/entity/character/character.cpp`

**文件含义**：`Character` 全部方法实现。本次核心新增扣血、回满、信号广播，以及在移动末尾调用碰撞处理。

### 函数说明（仅列本次新增或行为变更）

| 函数 | 说明 |
|------|------|
| `on_character_movement` | 在 `move_and_slide()` 之后增加 `process_slide_collisions()` 调用 |
| `is_alive()` | 委托 `m_health.is_alive()` |
| `take_damage(int hearts)` | 调用 `m_health.apply_damage`；有实际扣血则 `emit_hearts_changed()`；归零则 `emit_signal(died)` |
| `reset_hearts()` | `m_health.reset()` + `emit_hearts_changed()` |
| `emit_hearts_changed()` | `emit_signal(hearts_changed, m_health.hearts, m_health.max_hearts)` |
| `process_slide_collisions()` | 基类空实现，占位供多态 |
| `get_hearts()` / `get_max_hearts()` | 读取 `m_health` |
| `set_max_hearts(int)` | `m_health.set_max` + 广播 |
| `set_hearts(int)` | `std::clamp` 后写入 + 广播 |

## 4. `src/entity/character/player.hpp`

**文件含义**：玩家角色子类声明。重写碰撞处理，实现与关卡伤害区的交互。

### 类：`class Player`

| 函数 | 说明 |
|------|------|
| `Player()` | 设置唯一名 `Player`，`m_health.set_max(5)` |
| `void _ready() override` | 调用基类 `_ready`，并 `emit_hearts_changed()` 同步初始 HUD |
| `void process_slide_collisions() override` | 遍历 `get_slide_collision_count()`，检测新进入的碰撞体 |
| `void handle_zone_contact(PhysicsBody2D* body)` | 根据碰撞层判断伤害区/死亡区并扣血（私有） |

#### 成员变量

| 成员 | 说明 |
|------|------|
| `std::unordered_set<uint64_t> m_active_zone_colliders` | 本帧仍在接触中的碰撞体 instance id；用于「仅首次进入扣血」 |

## 5. `src/entity/character/player.cpp`

**文件含义**：玩家移动碰撞与关卡危险区域逻辑实现。

### 函数说明

| 函数 | 说明 |
|------|------|
| `Player::Player()` | 唯一名 + 5 心上限 |
| `Player::_ready()` | 基类初始化后广播初始血量 |
| `process_slide_collisions()` | 收集当前接触集合；对**新出现**的 collider 调用 `handle_zone_contact`；更新 `m_active_zone_colliders` |
| `handle_zone_contact(body)` | `LayerID::DeathZones` → `take_damage(get_max_hearts())`；`LayerID::DamageZones` → `take_damage(1)`；并写 Console 日志 |
| `_bind_methods()` | 当前为空（无额外 Godot 绑定） |

### 场景配置关联

`player.tscn` 中 `collision_mask = 56`：

| 层 | 位值 | 含义 |
|----|------|------|
| Walls | 8 | 墙体 |
| DamageZones | 16 | 伤害区（绿块） |
| DeathZones | 32 | 死亡区（红块） |

## 6. `src/ui/heart_hud.hpp`

**文件含义**：游戏内左上角心形 HUD 的 Godot 扩展类声明。继承 `Control`，自绘圆点，不依赖 Label/字体。

### 类：`class HeartHud`（命名空间 `rl::ui`）

| 函数 | 说明 |
|------|------|
| `void _ready() override` | 忽略鼠标、`z_index=100`；运行时 `call_deferred("connect_to_player")` |
| `void _draw() override` | 按 `m_current_hearts` / `m_max_hearts` 绘制红/灰圆点 |
| `void connect_to_player()` | 延迟执行：查找 Level → Player，连接信号，初次刷新 |
| `void update_hearts(int current, int max_hearts)` | 更新缓存、调整控件尺寸、`queue_redraw()` |
| `on_player_hearts_changed(int, int)` | `hearts_changed` 信号槽 → 调用 `update_hearts` |
| `on_player_died()` | `died` 信号槽 → Console 日志 + 显示 0 心 |

#### 成员变量

| 成员 | 说明 |
|------|------|
| `Player* m_player` | 绑定的玩家实例 |
| `int m_current_hearts` | 绘制用当前心数缓存 |
| `int m_max_hearts` | 绘制用最大心数缓存 |

## 7. `src/ui/heart_hud.cpp`

**文件含义**：HUD 初始化、节点查找、信号连接与 `_draw` 绘制实现。

### 匿名命名空间常量

| 常量 | 值 | 说明 |
|------|-----|------|
| `heart_radius` | 10.0f | 单颗心圆半径（像素） |
| `heart_spacing` | 28.0f | 圆心水平间距 |
| `heart_padding` | 8.0f | 控件内边距 |

### 函数说明

| 函数 | 说明 |
|------|------|
| `_ready()` | 非编辑器下延迟绑定玩家，避免初始化顺序问题 |
| `connect_to_player()` | 从 `SubViewport` 递归 `find_child(Level1, owned=false)`，再找 `Player`；连接 `hearts_changed` / `died` |
| `update_hearts()` | 计算宽高 `padding*2 + spacing*max`；触发重绘 |
| `_draw()` | 满心红色 `(1, 0.22, 0.33)`，空心灰色 `(0.28, 0.28, 0.34, 0.85)` |
| `on_player_hearts_changed()` | 转发至 `update_hearts` |
| `on_player_died()` | 打印死亡日志；UI 显示全部空心 |

### 节点查找路径

```
HeartHud
  └── parent: HudCanvasLayer
        └── parent: MainSubViewport
              └── find_child("Level1", recursive, owned=false)
                    └── find_child("Player", ...)
```

## 11. 运行时调用链

### 进入伤害区扣 1 心

```
PlayerController → character_move
  → Character::on_character_movement
    → move_and_slide()
    → Player::process_slide_collisions
      → handle_zone_contact (DamageZone)
        → Character::take_damage(1)
          → emit hearts_changed
            → HeartHud::on_player_hearts_changed
              → update_hearts → _draw
```

### 心数归零

```
take_damage → hearts == 0
  → emit died
    → HeartHud::on_player_died
  → (待 P0-B05) Level 监听 died → 重开关卡
```
