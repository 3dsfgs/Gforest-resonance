# v0.3 Day11–12 源码与函数说明

## 1. 信号链

```
Level::transition_to_state(Victory)
  → level_state_changed
  → Main::on_level_state_changed
  → emit run_victory
  → main.gd::_on_run_victory
  → ending_screen.tscn
```

`MainDialog` 在 Victory 时**不再**写 Console 胜利叙事（仅 Defeat 保留）。

## 2. 关键 / 关键文件

| 路径 | 说明 |
|------|------|
| `project/scripts/music_director.gd` | Autoload BGM 切换 |
| `project/scripts/ending_screen.gd` | 逐行 Tween 结语 |
| `project/scenes/ui/ending_screen.tscn` | 结语层 |
| `project/scripts/main.gd` | 接 `run_victory` |
| `project/scripts/birthday_gate.gd` | 进关前 `play_combat` |
| `project/scripts/title_screen.gd` | `play_title` |
| `src/main.*` | `return_to_title` / `run_victory` |
| `src/entity/level.cpp` | Victory 下禁用 R 重开 |
| `project/project.godot` | Autoload + 窗口名《林间回响》 |
