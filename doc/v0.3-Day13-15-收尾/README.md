## 3. 打包 exe

### 3.1 构建 Release DLL（必须）

```bat
scripts\build-release.bat
```

确认存在：`project/bin/roguelite.windows.64.release.dll`  

> ✅ 收尾阶段已在本机跑通 Release 构建。

### 3.2 Export Templates（首次，本机尚未检测到）

当前环境里还**没有**装好 Godot 4.7 Export Templates。请你本地做一次：

1. 打开 Godot 4.7  
2. **Editor → Manage Export Templates → Download and Install**（选 4.7.stable）  
3. 再跑 `scripts\export-windows.bat`

若 `project/export_presets.cfg` 不存在，脚本会从 `export_presets.cfg.example` 自动复制一份（该文件被 `.gitignore` 忽略属正常）。

### 3.3 导出

**方式 A（脚本）**

```bat
scripts\export-windows.bat
```

输出目录：`dist/windows/林间回响.exe`（及同目录 `.pck` 等）

**方式 B（编辑器）**

1. 打开 `project/`  
2. **Project → Export → Windows Desktop → Export Project**  
3. 选到 `dist/windows/`  

### 3.4 干净目录试跑

把 `dist/windows/` **整夹**拷到另一路径（或另一台机），双击 exe，确认能过标题进游戏。

> GDExtension 项目：导出后的包内需带上 extension 库；用官方 Export 即可，不要只拷单个 exe 而漏 `.pck`。
