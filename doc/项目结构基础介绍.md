## `src/` 目录结构总览

`src/` 是本项目的 **C++ 游戏逻辑核心**，所有 GDExtension 类都在这里注册、实现。整体按「入口 → 领域逻辑 → 基础设施」分层：

```
src/
├── api/              # GDExtension 入口与类注册
├── main.hpp/cpp      # 游戏根节点 Main
├── ui/               # UI 相关 C++ 节点
├── entity/           # 游戏实体（关卡、角色、投射物、相机、控制器）
├── singletons/       # 全局单例（如游戏内控制台）
├── core/             # 核心工具：常量、断言、属性/信号绑定宏
└── util/             # 引擎封装、输入、场景、调试等通用工具
```

---

### 各目录职责

| 目录 | 文件 | 作用 |
|------|------|------|
| **`api/`** | `extension_interface.cpp/hpp` | GDExtension 的 `extension_library_init` 入口；向 Godot 注册所有 C++ 类，并初始化 `Console` 单例 |
| **根目录** | `main.hpp/cpp` | 游戏总控节点 `Main`：加载 UI、挂载关卡、设置 FPS/分辨率 |
| **`ui/`** | `main_dialog.hpp/cpp` | 主界面面板 `MainDialog`：绑定游戏内控制台、控制关卡激活状态 |
| **`entity/`** | 见下表 | 所有游戏世界对象 |
| **`singletons/`** | `console.hpp` | 模板单例 `Console<RichTextLabel>`：spdlog + 游戏内日志面板 |
| **`core/`** | `constants.hpp`, `bind.hpp`, `assert.hpp` 等 | 节点名/路径/信号名常量；`[[signal_slot]]`/`[[property]]` 宏；编译期断言 |
| **`util/`** | `engine`, `input`, `scene`, `bind` 等 | 对 Godot API 的薄封装，减少样板代码 |

#### `entity/` 子目录

```
entity/
├── level.hpp/cpp           # 关卡：生成 Player、ProjectileSpawner，处理碰撞/射击信号
├── character/
│   ├── character.hpp/cpp   # 角色基类（移动、旋转、射击）
│   ├── player.hpp/cpp      # 玩家
│   └── enemy.hpp/cpp       # 敌人
├── controller/
│   ├── character_controller  # 输入控制基类
│   ├── player_controller     # 玩家键鼠输入
│   └── enemy_controller      # AI 控制
├── projectile/
│   ├── projectile            # 子弹实体
│   └── projectile_spawner    # 子弹生成器
└── camera.hpp/cpp            # 跟随角色的相机
```

**设计模式要点：**
- **场景 (.tscn) + C++ 混合**：视觉结构在 Godot 编辑器里搭，逻辑在 C++ 里写
- **Controller 分离**：`Character` 管物理/动画，`CharacterController` 管输入，便于复用（玩家/敌人共用 `Character`）
- **信号驱动**：角色发 `spawn_projectile`、`position_changed`，`Level` 监听并处理

## 对照 README 第 27–46 行：节点层级图

README 画的是 **运行时 Godot 节点树** 与 **对应 C++ 类** 的映射关系，不是单纯的文件夹结构。用更清晰的方式表示如下：

```
Main                          ← src/main.hpp（main.tscn 根节点）
└── MainDialog                ← src/ui/main_dialog.hpp（来自 main_dialog.tscn）
    ├── RichTextLabel         ← 游戏内控制台（ConsolePanel）
    └── MainSubViewport       ← 主游戏视口
        └── Canvas Layer
            └── Level         ← src/entity/level.hpp（运行时由 Main 挂上去）
                ├── Player    ← src/entity/character/player.hpp
                │   ├── [player.tscn 场景节点]   ← project/scenes/characters/player.tscn
                │   ├── CharacterController      ← 控制器子节点
                │   ├── Camera                   ← src/entity/camera.hpp
                │   └── FiringPoint (Marker2D)   ← 来自 player.tscn，C++ 里引用
                └── ProjectileSpawner
                    └── Projectile（运行时生成）

Console (Singleton)           ← src/singletons/console.hpp（全局单例，不是场景子节点）
    └── 输出到 RichTextLabel  ← MainDialog::_ready() 里绑定
```

## README 图示的几个注意点

1. **HTML 链接在 GitHub 外不太好看**  
   那段 `<div class="highlight">` 是为 GitHub 渲染准备的，在 Cursor 里会直接显示原始 HTML。

2. **README 把 `Level` 画成 `Main` 的直接子节点**  
   实际代码里 `Level` 是挂到 `MainDialog` 内部的 `MainCanvasLayer` 上，逻辑上仍由 `Main` 在构造函数里完成挂载。

3. **`Console` 和底部 `RichTextLabel` 是同一东西的两面**  
   - `Console`：C++ 单例，负责日志  
   - `RichTextLabel`：`.tscn` 里的 UI 控件，Console 把文字写到这里

4. **`main.tscn` 本身很薄**  
   根节点类型是 `Main`（C++ 类），还挂了一个极简的 `main.gd` 脚本处理示例信号，大部分逻辑在 C++。

| 类 | 类型 |
|----|------|

| `CharacterController`, `PlayerController`, `EnemyController` | 控制器 |
| `Camera`, `Projectile`, `ProjectileSpawner` | 组件 |
| `console` | 单例 |
