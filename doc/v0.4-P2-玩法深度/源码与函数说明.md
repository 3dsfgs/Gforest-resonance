## 1. 数据：`project/data/room_chain.json`

| 字段 | 含义 |
|------|------|
| `chain_template[]` | 当晚槽位顺序；每项含 `slot`（房型）+ `pool` 或 `fixed` |
| `rooms.<pool_id>[]` | 池：数组，开局 `randi % size` 抽一间 |
| `rooms.<fixed_id>` | 固定房：单个对象 |
| 房条目 `scene` | `res://...tscn` 路径 |
| 房条目 `display_name` / `tagline` | 过场地名卡文案 |
| `whisper_01.whispers` | 低语房独白池（场景侧脚本另有默认文案） |

首版模板顺序：

```
combat_early → combat_mid → whisper → mood → combat_late → boss
```

改房序 / 加房：只改 JSON，不必改 C++。

| 函数 | 说明 |

## 3. C++ `Main`（`src/main.hpp` / `main.cpp`）

### 数据结构

```cpp
struct RunRoomEntry {
    godot::String scene_path;
    godot::String display_name;
    godot::String room_kind;  // "combat" | "whisper" | "mood" | "boss"
    bool is_final;
};
std::vector<RunRoomEntry> m_run_rooms;
```

### 函数

| 函数 | 说明 |
|------|------|
| `configure_run(Array rooms)` | GDScript 注入当晚链；字典键见上；空则 `seed_legacy_run` |
| `begin_run()` | 若 `m_run_rooms` 空则旧三房兜底；`load_room(0)` |
| `load_room(index, hearts)` | 按 `m_run_rooms[index].scene_path` 实例化；设 `room_index` / `room_kind` / `is_final` |
| `parse_room_kind(String)` | 字符串 → `RoomKind` 枚举 |
| `on_room_cleared(index)` | 下一房 `display_name` 取自 `m_run_rooms`；emit `room_advance_requested` |
| `return_to_title()` | 卸关卡并 `m_run_rooms.clear()` |
| `seed_legacy_run`（匿名） | 兼容旧 `path::scene::room_paths` + `room_display_names` |

> **禁止**在 GDScript 里 `func begin_run()` override C++ 方法（Godot 会 Parser Error）。开战入口见下节。

## 4. C++ `Level`（`src/entity/level.hpp` / `level.cpp`）

### 新增枚举 / 状态

```cpp
enum class RoomKind { Combat, Whisper, Mood, Boss };
RoomKind m_room_kind{ RoomKind::Combat };
bool m_is_final_room{ false };
```

### 函数

| 函数 | 说明 |
|------|------|
| `set_room_kind` / `set_is_final_room` | 由 `Main::load_room` 在 `_ready` 前写入 |
| `request_room_clear()` | **仅** Whisper / Mood 可调；内部 `complete_room()`；已绑定到 GDScript |
| `complete_room()` | 停输入；若 `m_is_final_room` → Victory；否则 emit `room_cleared` |
| `on_enemy_died()` | 清完怪后改调 `complete_room()`（不再用 `room_index >= room_count-1`） |
| `_ready` / `reset_level` | **仅** Combat / Boss 调用 `spawn_enemies_from_markers()` |

非战斗房无敌人 Marker → 不刷怪；靠 `request_room_clear` 推进。

## 6. 非战斗房流程

### 低语 `whisper_room_flow.gd`

- `_build_ui`：底部独白 Label +「按 E」提示
- `_show_line`：翻句；`_advance_armed` + `sync_key_state`
- 末句后再推进 → `Level.request_room_clear()`

### 心境 `mood_room_flow.gd`

- 居中「找回/唤醒」文案占位（P2-1 接入武器选择前）
- 按 E → `request_room_clear()`

### 输入 helper `room_advance_input.gd`

Godot 4.7 **没有** `Input.is_physical_key_just_pressed` / `is_key_just_pressed`。

| 函数 | 说明 |
|------|------|
| `sync_key_state()` | 武装推进前同步「当前是否已按住」，避免进房瞬间连触 |
| `poll_advance()` | `interact` / `ui_accept` 的 `just_pressed`，或 `is_physical_key_pressed(KEY_E)` 边沿 |

原因：`MainSubViewport` 配置了 `handle_input_locally=false`、`gui_disable_input=true`，关卡内 `_unhandled_input` 收不到键盘；必须与 C++ 一样走全局 `Input`。

### 输入映射

`project.godot` 新增：

```
interact → physical_keycode E (69)
```

过场短句：`room_transition.gd` 扩展 `ROOM_TAGLINES`（低语/心境/心魔/光扉等），并可用 `DreamRoomChain.get_tagline` 兜底。

## 8. 流程时序

```

  → configure_run(DreamRoomChain.build_run_config())
  → begin_run() → load_room(0)
```

## 11. P2-3 分波刷怪（`src/entity/level.*`）

### Marker 约定

| 命名 | 波次 |
|------|------|
| `EnemySpawn*` / `EnemyBruteSpawn*` / `EnemyBossSpawn*`（无 W#） | 1 |
| 名中含 `W2` | 2 |
| 名中含 `W3` | 3 |

### 状态

```
std::vector<std::vector<WaveSpawnPoint>> m_waves;
int m_current_wave{ 0 };
double m_wave_breath_remaining{ -1.0 };  // <0 = 未在喘息
```

常量：`spawn::wave_breath_duration`（默认 1.15s）。

### 函数

| 函数 | 说明 |
|------|------|
| `collect_wave_markers()` | 扫子节点 Marker → 按波号 `map` → 填入 `m_waves` |
| `parse_wave_index(name)` | `W3`→3 / `W2`→2 / 默认 1 |
| `start_wave(index)` | 清空 pending，对该波 `queue_enemy_spawn`（仍走预警圈） |
| `try_finish_current_wave()` | `enemy_count==0` 且 pending 空：有下一波则开喘息，否则 `complete_room` |
| `update_wave_breath(delta)` | 喘息结束 → `start_wave(current+1)` |
| `on_enemy_died()` | 减计数后调 `try_finish_current_wave`（不再直接 complete） |

`spawn_enemies_from_markers()`：收集波次后 `start_wave(0)`。  
`reset_level` / `clear_enemies`：重置喘息计时。

### 场景改动

`level1` / `level2` / `level3` / `boss_room` 均拆为 ≥2 波 Marker。

## 12. P2-1 武器系统

### 数据 `project/data/weapon_rules.json`

字段：`id` / `display_name` / `recall_line` / `type` / `fire_rate` / `damage_hearts` / `spread_radians` / `pellet_count` / `impulse`。

### C++ `src/util/weapon_rules.*`

| 函数 | 说明 |
|------|------|
| `ensure_loaded()` | 读 JSON 缓存 |
| `get(id)` / `get_default()` | 查表，缺省回退 pulse |
| `apply_to_spawner(spawner, weapon, fire_rate_mult)` | 写射速/散射/弹丸/伤害/冲量 |

### Spawner / Projectile

- `try_begin_shot()` / `create_projectile()`：霰弹一次冷却多弹
- `Projectile::set_damage_hearts`
- `Level::spawn_projectile_from_marker`：玩家按 `pellet_count` 扇形散射

### 跨房

- `Main::m_weapon_id` + `set_run_weapon` / `get_run_weapon`
- `load_room` 前 `Level::set_weapon_id`；`_ready` 内 `apply_player_weapon`
- 清房时从 Level 回写 Main

### 心境房 `mood_room_flow.gd`

←/→ 或 1/2 选 `pistol`/`shotgun` → E → `apply_player_weapon` + `set_run_weapon` → 短停 → `request_room_clear`。

近战与地面掉落拾取未做（范围收敛）。
