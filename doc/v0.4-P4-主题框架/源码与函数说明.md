# v0.4 P4 · 源码与函数说明

## 数据

| 路径 | 作用 |
|------|------|
| `project/data/theme.json` | 主题表：`active_theme` / `title_preview_theme` / `themes.*` |
| `project/data/room_chain.json` | 森林默认房链（由 theme.`room_chain` 指向） |

## 脚本

| 路径 | 职责 |
|------|------|
| `project/scripts/theme_catalog.gd` | Autoload：读表、取 BGM/底图/标题文案/房名短句 |
| `project/scripts/music_director.gd` | `_resolve_path` 优先 ThemeCatalog |
| `project/scripts/title_screen.gd` | 标题底图/veil/文案/预告 hint |
| `project/scripts/dream_room_chain.gd` | `room_chain` 路径来自主题；生成时叠 `room_names` tagline |
| `project/scripts/room_transition.gd` | tagline 优先 ThemeCatalog |
| `project/scripts/combat_room_presentation.gd` | 按房型/链序覆盖 `BackgroundTexture` |

## Autoload 顺序（`project.godot`）

`ThemeCatalog` → `DreamRoomChain` → `MusicDirector`

## 关键 API

- `ThemeCatalog.get_bgm("combat")`
- `ThemeCatalog.get_bg_for_room(room_kind, chain_index)`
- `ThemeCatalog.get_title_bg_path()` / `get_preview_hint()`
- `ThemeCatalog.get_room_chain_path()`
- `ThemeCatalog.set_active_theme(id)`（运行时切换，供未来选关）
