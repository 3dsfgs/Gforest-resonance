# Demo v0.2 定义与验收标准

> **版本**：Demo v0.2（P0 阶段四收尾）  
> **目标**：在 v0.1 MVP 可玩闭环基础上，补齐**视差森林氛围**、**占位美术辨识度**与**敌人/子弹对象池**，为 P1 技能与多实体战斗打底。  
> **关联**：[开发排期与里程碑](./开发排期与里程碑.md) · **[任务/P0-v0.2-视觉与性能开发任务](./任务/P0-v0.2-视觉与性能开发任务.md)** · [MVP定义与验收标准](./MVP定义与验收标准.md)

---

## 1. v0.2 一句话

玩家在**同一张森林关卡**中，获得**有景深的视差背景**与**可辨识的占位美术**；在**同屏更多敌人与子弹**时仍保持流畅；**v0.1 全部玩法与闭环不退化**。

---

## 2. 范围内（Must Have）

| # | 功能 | 验收标准 |
|---|------|----------|
| V1 | 视差森林背景 | 2–3 层 `ParallaxBackground`；移动时有景深感 |
| V2 | 占位美术统一 | 玩家/敌人/地面/背景可一眼区分 |
| V3 | 敌人对象池 | 从池激活/回收；`reset_level` 后状态正确 |
| V4 | 子弹对象池 | 脉冲发射走池化；命中/超时回收而非仅 `queue_free` |
| V5 | 性能指标 | 同屏 **10 敌 + 20 弹**，1080p **稳定 60 FPS** |
| V6 | v0.1 回归 | M1–M8 演示检查清单仍全部通过 |
| V7 | 可构建运行 | `configure-and-build` 通过；F5 能启动 |

---

| 功能 | 计划阶段 |

---

## 4. 体验指标

| 指标 | 目标 |
|------|------|
| 单次可玩时长 | 3–5 分钟（与 v0.1 相当） |
| 崩溃 | 连续 3 轮全流程 0 崩溃 |
| 帧率 | 压力场景（10 敌 + 20 弹）1080p ≥ 60 FPS |
| 视觉 | 静止截图可区分玩家、敌人、远景、近景 |

---

## 5. 降级方案

| 风险 | 降级 |
|------|------|
| 视差素材未就绪 | 1 层远景贴图 + 纯色近景 |
| AI 美术未导入 | 几何色块 + 统一色调区分实体 |
| 对象池实现卡住 | 先完成子弹池；敌人仍 instantiate，文档记录技术债 |
| 10 敌压力不达标 | 降至 8 敌 + 15 弹，记录实测帧率 |

---

## 6. 演示检查清单

- [ ] 启动到进关卡 < 30 秒
- [ ] 移动时背景各层视差速度不同、无穿帮
- [ ] 玩家/敌人/背景视觉可辨识
- [ ] 脉冲射击、受击、无敌帧、死亡重开、清敌胜利均正常
- [ ] 压力场景（10 敌 + 20 弹）无明显卡顿
- [ ] 连续 3 轮无崩溃
- [ ] `reset_level` 后敌人与子弹池状态复位
