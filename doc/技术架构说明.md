# 技术架构说明

> **关联**：[独立游戏项目计划书](./独立游戏项目计划书.md) · [开发排期与里程碑](./开发排期与里程碑.md)

---

## 1. 总览

- **引擎**：Godot 4.5 + GDExtension (C++)
- **玩法**：2D 俯视角（WASD + 鼠标瞄准）
- **构建**：CMake + vcpkg（fmt、spdlog）

---

## 2. `src/` 模块

| 目录 | 职责 |
|------|------|
| `api/` | GDExtension 入口、类注册 |
| `main` | 根节点与流程 |
| `entity/` | Level、Player、Enemy、Projectile |
| `ui/` | MainDialog（C++） |
| `singletons/` | Console 单例 |
| `core/` | 常量、信号、绑定宏 |
| `util/` | 引擎/输入/场景封装 |

---

## 3. C++ vs GDScript

| C++ | GDScript |
|-----|----------|
| 战斗、数值、Buff、HTTP API | 菜单、设置、图鉴 |
| 对象池、敌人生成 | 生日输入、叙事 UI 布局 |

---

## 4. 赛博八字管线（P1）

```
生日输入 → C++ 请求 API → JSON → buff_rules.json 映射 → 属性修正
         → user://profile.json
```

降级：Mock JSON + 固定命格。

---

## 5. 性能与构建

- 对象池、异步 ResourceLoader
- 不早期拆 CoreSystem 静态库
- 构建：`scripts/configure-and-build.bat`
