# v0.4 P3 · 源码与函数说明

## 数据

| 路径 | 作用 |
|------|------|
| `project/data/story.json` | OP/ED `panels[]`：`image` / `duration` / `caption` |
| `project/data/monologue.json` | 独白池 + 性情微调句 |
| `project/data/buff_rules.json` | 性情底色；新增 `story_hook`；弱化 `buff_summary` 措辞 |
| `user://profile.json` | 档案；新增 `story_hook` / `skipped` / `birthday_today` |

## 脚本

| 路径 | 职责 |
|------|------|
| `project/scripts/story_sequence.gd` | JSON 加载、淡入、轻量 scale Ken Burns、点击翻页、`finished` |
| `project/scripts/main.gd` | `play_opening_then_run` / `play_story_sequence` / 锚点夜日 / Victory→ED→结语；挂 `MonologueHud` |
| `project/scripts/birthday_gate.gd` | 性情 UI、年龄校验、跳过、生日彩蛋标记、确认后走 OP |
| `project/scripts/monologue_hud.gd` | 底部半透明独白；进房/清房/受击/Boss；读 `hearts_changed` |
| `project/scripts/bedroom_anchor.gd` | 夜/日 TextureRect（由 main 包一层 CanvasLayer 短亮） |
| `project/scripts/ending_screen.gd` | 醒来向结语文案（与 ED 呼应） |
| `src/util/birth_buff.cpp` | 控制台打印「性情底色」 |

## 场景

| 路径 | 说明 |
|------|------|
| `project/scenes/prefabs/story_sequence.tscn` | 分镜壳 |
| `project/scenes/story/op_sleep_to_dream.tscn` | `sequence_key = "op"` |
| `project/scenes/story/ed_wake_up.tscn` | `sequence_key = "ed"` |
| `project/scenes/prefabs/bedroom_anchor.tscn` | 卧室锚点 |

## 关键入口

- **入梦**：`BirthdayGate._commit_and_enter` → `Main.play_opening_then_run()`  
  → 锚点夜 → `play_story_sequence("op")` → `start_dream_run()`
- **醒来**：`Main._on_run_victory` → 卸关卡 → `play_story_sequence("ed")`  
  → 锚点日 → `EndingScreen`
- **独白**：`start_dream_run` / `room_advance_requested` 后定时调用 `MonologueHud.on_room_*`
