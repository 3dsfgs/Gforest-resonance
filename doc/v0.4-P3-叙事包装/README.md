## 走测中发现并修复

| 问题 | 根因 | 修复 |
|------|------|------|
| OP/ED 字幕大黑块挡住漫画 | `CaptionPanel` 缺 `anchor_top=1`，底板几乎铺满全屏 | 强制贴底锚点；画面全出血；字幕半透明且晚于画面淡入 |

| 项 | 怎么测 |
|----|--------|
| B3 入梦分镜 | 开始旅程 → 确认/跳过 → 应看到卧室夜态 → **6 格** OP（点击翻页）→ 进雾缘 |
| B6 因果可读 | 能说清：累了才做梦；打的是暗影；醒来是歇一歇 |
| B6 无「命格」 | 生日门全文应为「性情底色」；控制台为「性情底色」 |
| B6 独白 ≥3 | 雾缘/深心/光扉幕首、清房、受击、Boss 前至少注意 3 处 |
| B7 醒来包装 | Boss 通关 → ED **5 格** → 卧室日态 → 治愈结语 |
| P3-6 跳过 | 「跳过，直接入梦」可用默认性情进 OP |
| P3-6 年龄 | 年设为今年（&lt;8）或 1800（&gt;120）应有友好提示 |
| P3-6 生日当天 | 月日改成今天 → 测算后有生日提示；进房有专属低语 |
